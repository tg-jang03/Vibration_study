# 공통 랩 부품 확인 (M1.3)

개발용 확인 페이지다. 모든 랩은 `LabFrame` 틀 안에서 **조작 → 플롯 → 수식·읽음값 → 실험 과제** 순서로 구성한다.
본문 글은 읽기 좋은 폭으로, 랩은 화면 폭까지 넓게 쓴다.

슬라이더는 손잡이와 숫자만 즉시 움직이고, 계산과 그리기는 화면 갱신(프레임)당 한 번만 한다.
