### 1-2. 개념 순서 규칙 (가장 중요)

1. 페이지는 **앞 페이지까지 설명한 개념만** 쓴다. 뒤에서 다룰 개념이 꼭 필요하면 한 줄로 풀고 "(P1-4에서 자세히)"처럼 위치를 밝힌다.

**신호 성분** (`SignalSpec`, `src/lib/dsp/signal.ts`): `sine`(f, A, φ), `harmonics`(f₀, 차수별 A·φ), `noise`(백색 가우시안, rms, seed) — M1.1, `chirp`(선형 처프, 런업·코스트다운) — M1.7, `impulses`(감쇠 임펄스열: 반복 주파수, 울림 주파수, 시정수, 첫 충격 시각 — 기어 이빨 결함 충격) — M1.12. `modulated`(반송파·변조 주파수·AM 지수 m·FM 지수 β·둘 사이 위상차 — AM, FM, AM + FM) — M1.14.

**핵심 식 (KaTeX 원문)** — 페이지와 랩은 이 표기를 그대로 쓴다.

- 나이퀴스트: `f_N = \dfrac{f_s}{2}`
- 에일리어스 주파수: `f_a = \left| f - k f_s \right|,\quad k = \operatorname{round}(f / f_s)`
- ADC 양자화 SNR (풀스케일 정현파): `SNR \approx 6.02\,b + 1.76\ \mathrm{dB}`
- 분해능 3식: `\Delta f = \dfrac{F_{max}}{\mathrm{LOR}},\quad T = \dfrac{1}{\Delta f},\quad N = 2.56\,\mathrm{LOR}`
- DFT: `X[k] = \sum_{n=0}^{N-1} w[n]\,x[n]\,e^{-j 2\pi k n / N}`
- 단일측 피크 진폭: `A_k = \dfrac{2\,|X[k]|}{S_1}` (0 < k < N/2. k = 0과 N/2에는 2를 곱하지 않음)
- 파워 스펙트럼 (rms²): `PS_k = \dfrac{2\,|X[k]|^2}{S_1^2}`
- PSD: `PSD_k = \dfrac{2\,|X[k]|^2}{f_s\,S_2} = \dfrac{PS_k}{\mathrm{ENBW}\cdot\Delta f}`
- 윈도우 계수: `CG = \dfrac{S_1}{N},\; ACF = \dfrac{N}{S_1},\; ECF = \sqrt{\dfrac{N}{S_2}},\; \mathrm{ENBW} = \dfrac{N S_2}{S_1^2}`
- 지수 평균: `\bar S_m = (1-\alpha)\,\bar S_{m-1} + \alpha\, S_m`
- 오버랩 총 측정시간: `T_{tot} = T\,[\,1 + (M-1)(1-r)\,]`
- ASD: `ASD_k = \sqrt{PSD_k}` (단위 mm/s/√Hz)
- 대역 RMS (overall): `\sqrt{\dfrac{\sum_k PS_k}{\mathrm{ENBW}}} = \sqrt{\sum_k PSD_k\,\Delta f}` (k는 대역 안의 bin, ENBW는 bin 단위)
- derived peak: `\sqrt 2\,A_{rms}` (정현파 하나일 때만 true peak와 같다)
- 파워 평균 흔들림 (dB, 경험칙): `\approx 4.34/\sqrt{M}`
- TSA: `\bar x(\theta) = \dfrac{1}{M}\sum_{m=0}^{M-1} x(\theta + 2\pi m)`
- TSA 비동기 성분 이득: `|H(f)| = \left| \dfrac{\sin(\pi M f / f_r)}{M \sin(\pi f / f_r)} \right|`
- dB: `L = 20\log_{10}(A / A_{ref})`
- 정현파 진폭 관계 (정현파일 때만 성립): `A_{rms} = \dfrac{A_{pk}}{\sqrt 2},\quad A_{pp} = 2 A_{pk}`
- Crest factor: `CF = \dfrac{A_{pk}}{A_{rms}}`
- 변위·속도·가속도 (정현파): `v = 2\pi f\, d,\quad a = (2\pi f)^2 d`
- AM: `(1 + m\cos 2\pi f_m t)\cos 2\pi f_c t` → 측대역 f_c ± f_m, 진폭 m/2
- FM: `\cos(2\pi f_c t + \beta\sin 2\pi f_m t) = \sum_n J_n(\beta)\cos 2\pi(f_c + n f_m)t`
- 맥놀이: `\cos 2\pi f_1 t + \cos 2\pi f_2 t = 2\cos\pi(f_1 - f_2)t\,\cos\pi(f_1 + f_2)t`
- 증폭계수 (Half-power): `AF = \dfrac{N_c}{N_2 - N_1} \approx \dfrac{1}{2\zeta}` (N₁, N₂: 피크 진폭의 0.707배 지점, I-004)
- 1자유도 불평형 응답: `\dfrac{X}{m_u e / M} = \dfrac{r^2}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}},\quad \phi = \operatorname{atan2}(2\zeta r,\ 1-r^2),\quad r = \dfrac{N}{N_n}`
- Log decrement: `\delta = -\dfrac{2\pi\sigma}{\omega_d} \approx 2\pi\zeta`
- 1X 벡터와 Slow roll 보상: `\vec V = A\,e^{-j\phi}`, `\vec V_c = \vec V - \vec V_{sr}`
- 트래킹 필터 (lock-in): `\vec V_{nX}(t) = 2\,\mathrm{LPF}\{x(t)\,e^{-jn\theta(t)}\}`
- FRF 추정, 코히어런스: `H_1 = \dfrac{G_{xy}}{G_{xx}},\; H_2 = \dfrac{G_{yy}}{G_{yx}},\; \gamma^2 = \dfrac{|G_{xy}|^2}{G_{xx}G_{yy}}`
- 영향계수 밸런싱: `H = \dfrac{\vec V_1 - \vec V_0}{\vec W_t},\quad \vec W_c = -\dfrac{\vec V_0}{H}`
- 요소 주파수 (P0-7, D-032): `f_{GM} = z\,f_r`, `f_{BP} = N_b\,f_r`, `f_{FTF} = \dfrac{f_r}{2}\left(1 - \dfrac{d}{D}\cos\alpha\right)`, `f_{BPFO} = N_r f_{FTF}`, `f_{BPFI} = N_r (f_r - f_{FTF})`, `f_{BSF} = \dfrac{D}{2d} f_r \left(1 - \left(\dfrac{d}{D}\cos\alpha\right)^2\right)`, `f_{belt} = \pi D_p f_r / L` (D_p 풀리 지름, L 벨트 길이). P0-7은 α = 0과 근사(FTF ≈ 0.4 f_r)만 쓴다
- 베어링 결함 주파수: 원본 4-2 식 사용 (BSF 관례는 I-008). 위 요소 주파수 식과 같다

#### LAB-BAS-01 정현파의 세 숫자 (진폭 · 주파수 · 위상)
- P0-2 · M1.T2, M2.2 · 검토 (`SineBasicsLab`, P1-0에서 이동 완료, D-027)
- 목적: 정현파 하나가 진폭·주파수·위상 세 숫자로 정해지고, 세 숫자가 서로 독립이라는 것을 체감한다. 위상을 시간 어긋남 Δt로 읽는다.
- 신호: A·cos(2π f t + φ), 표시 0~1 s. 비교용 기준 파형(A = 1, φ = 0°) 점선
- 조작: A (0.2~2), f (1~20 Hz), φ (−180°~180°, 15° 간격), 기준 파형 표시 토글
- 출력: 시간파형. 읽음값 — 주기 T, 1초당 반복 횟수, Peak, 기준 대비 앞섬/늦음
- 수식: x(t) 대입식, T = 1/f, Δt = (φ/360°)·T (φ > 0 앞섬, φ < 0 늦음)
- 실험 과제: f 5 → 10 Hz에서 T와 물결 수, φ = −90°의 늦음 시간, φ = 180° = 부호 반대, A를 바꿔도 T 불변
- 검증: f = 5 Hz, φ = −90° → Δt = −0.05 s

#### LAB-BAS-02 진폭을 숫자 하나로 (Peak · Pk-Pk · RMS · Crest factor)
- P1-0 · M1.T2 · 구현 (`AmplitudeMeasuresLab`)
- 목적: 같은 Peak라도 모양에 따라 RMS가 다르고, RMS = Peak/√2 환산은 정현파 하나일 때만 맞는다는 것을 확인한다.
- 신호: 네 모양 모두 Peak = 1로 정규화 후 크기 배율을 곱함 — 정현파 5 Hz / 5 Hz + 15 Hz(0.6) / 사각파 / 0.1 s마다 감쇠 충격(180 Hz, τ = 4 ms) + 작은 5 Hz. 0.4 s, 4000점
- 조작: 신호 모양, 크기 배율 (0.5~3)
- 출력: 시간파형 + ±Peak 점선, RMS 실선. 읽음값 — Peak, Pk-Pk, RMS(직접 계산), CF, Peak/√2, 환산 오차 [%]
- 수식: x_rms = √(mean x²), CF = Peak/RMS, 정현파 가정 환산
- 검증 (배율 1): RMS / CF / 환산 오차 — 정현파 0.707 / 1.41 / 0 %, 두 정현파 0.516 / 1.94 / +37 %, 사각파 1.000 / 1.00 / −29 %, 충격 0.136 / 7.36 / +420 %

- 구현: P0-1 기본 모드는 x₀ 2~20 mm와 변위 표시, 애니메이션·그래프 축척은 20 mm 기준으로 고정(당기는 거리에 따라 폭이 달라 보이게, 2026-10-06 검토). P0-2 확장 모드는 m·k·x₀·v₀, 표시 x/v/a, fₙ·T·A·현재 x/v/a 읽음값. 첫 렌더는 t = 0 정지 상태이며 재생 뒤에만 requestAnimationFrame 사용

#### LAB-DAMP-01 감쇠 자유진동
- P0-3 · M2.3 · 검토 (`DampingLab`)
- 목적: 감쇠비 ζ가 진폭이 줄어드는 빠르기를 정하고 박자는 거의 바꾸지 않는다는 것, 연속 피크 비로 ζ를 읽을 수 있다는 것을 본다.
- 신호: 부족감쇠 `x(t) = x_0 e^{-\zeta\omega_n t}\left(\cos\omega_d t + \dfrac{\zeta\omega_n}{\omega_d}\sin\omega_d t\right)` (v₀ = 0), ζ ≥ 1이면 임계·과감쇠 해. f_n 기본 5 Hz
- 조작: ζ (0~1.5, 기본 0.05), f_n (1~20 Hz), x₀, 포락선 표시, 피크 표시
- 출력: 파형 + 초기조건을 반영한 포락선 ±Ae^(−ζω_n t), 같은 방향의 양의 피크. 읽음값 — ω_d/ω_n, 그려진 파형의 첫 두 피크에서 잰 피크 비·대수감쇠율 δ(이론값과 비교), δ로 추정한 ζ vs 설정 ζ, 진폭이 절반이 되는 주기 수. ζ ≥ 1에서는 비진동 해와 해당 없음(—) 표시
- 검증: ζ = 0.05 → δ = 2πζ/√(1−ζ²) = 0.3146, ω_d/ω_n = 0.99875, 반감 주기 수 = ln 2/δ ≈ 2.2. ζ = 1, x₀ > 0, v₀ = 0 → 부호가 바뀌지 않고 0으로 복귀

#### LAB-FRC-01 강제진동과 공진
- P0-4 · M2.4 · 검토 (`ForcedVibrationLab`)
- 목적: 정상상태 응답이 가진 주파수로 흔들리고, 진동수비 r에 따라 진폭비와 위상(0° → 90° → 180°)이 바뀌며, 공진 피크가 약 1/(2ζ)라는 것을 시간 응답과 주파수응답 곡선에서 함께 본다.
- 신호: `m\ddot x + c\dot x + kx = F_0\cos\omega t`의 해석해 = 과도(정지 상태에서 시작) + 정상상태. 힘 파형을 겹쳐 그림
- 조작: 가진 주파수 f (0~3 f_n) 또는 자동 스윕, ζ (0.01~0.5, 0.005 간격 — 0.025를 고를 수 있게), 표시 [과도 포함 / 정상상태만]
- 출력: (1) 힘과 변위의 시간파형 (2) 진폭비·위상 vs r 곡선 + 현재 점. 읽음값 — r, X/X_st, φ, 1/(2ζ)
- 검증: ζ = 0.05 → r = 1: X/X_st = 10.0, φ = 90° / r = 0.5: 1.330, 3.8° / r = 2: 0.3326, 176.2°. 최대값 1/(2ζ√(1−ζ²)) = 10.01 (r = √(1−2ζ²) = 0.9975)

#### LAB-2DOF-01 2자유도 모드
- P0-5 · M2.5 · 검토 (`TwoDofModeLab`)
- 목적: 질량 2개 계에는 고유진동수와 모드 형상이 2개씩 있고, 아무렇게나 건드리면 두 모드가 섞여 복잡한 파형이 된다는 것을 본다.
- 신호: 벽–k–m₁–k_c–m₂–k–벽 (감쇠 없음), 모드 분해로 만든 해석해
- 조작: m₁ = m₂ = m (선택: 비대칭 질량), k, 가운데 스프링 k_c (0.05k~2k), 초기 조건 [모드 1 / 모드 2 / 왼쪽만 당김]
- 출력: 두 질량 애니메이션, x₁(t)·x₂(t) (모드 형상 그림은 본문 그림 2가 맡는다). 읽음값 — f₁, f₂, 모드 1·2 형상 비 x₂/x₁, 처음 변위 중 모드 1·2 몫, 1/(f₂ − f₁)
- 검증: m₁ = m₂ = m → ω₁ = √(k/m), ω₂ = √((k + 2k_c)/m), 모드 [1, 1], [1, −1]. k_c = k → ω₂/ω₁ = √3. 모드 1 초기 조건이면 계속 x₁ = x₂

#### LAB-UNB-01 불평형 런업 입문

- 목적: 불평형이 회전수와 같은 주파수(1X)로 도는 힘을 만들고, 그 힘이 회전수 제곱으로 커지며, 1X가 고유진동수를 지날 때(임계속도) 진폭이 커지고 위상이 바뀐다는 것을 본다. LAB-AF-01의 입문판 (Half-power·Polar·분리여유 없음)

- 출력: 도는 원판 + 불평형 위치·원심력 화살표, 수평 변위 파형, 진폭·위상 vs rpm 곡선 + 현재 점. 읽음값 — 1X [Hz], 불평형 힘, r, 진폭, 위상
- 검증: 3000 rpm → 1X = 50 Hz. rpm 2배 → 힘 4배. ζ = 0.05, r = 1 → 진폭 = 10·m_u e/M, 위상 90°. r ≫ 1 → 진폭 → m_u e/M, 위상 → 180°

#### LAB-FMAP-01 주파수 지도: 기계 요소별 관심 구간
- P0-7 · M2.7 · 구현 (`FrequencyMapLab`, prop `initialPreset`. 계산 `lib/machine/frequencies.ts`·`frequencyMap.ts` — 본문 그림 6 ~ 10과 같은 계산)
