# Glossary — 용어집

> 사이트에 나오는 용어와 **처음 설명하는 페이지**를 모은다 (D-024). 페이지를 쓸 때 이 표로 "이 용어가 앞 페이지에서 설명됐나"를 대조한다.
> - 새 용어를 쓰면: 그 페이지 안에서 정의하고 여기에 한 줄 추가한다.
> - 앞 페이지에서 설명된 용어를 쓰면: 페이지 맨 위 "선수 개념" 표에 넣는다.
> - "처음 나오는 곳"보다 앞 페이지에서는 그 용어를 쓰지 않는다. 꼭 필요하면 한 줄 설명 + "(P1-x에서 자세히)".
> 나중에 사이트의 용어집 페이지(REF-2)로 보여준다.

| 용어 | 기호·단위 | 한 줄 뜻 | 처음 나오는 곳 |
|---|---|---|---|
| 진동 신호 | — | 센서가 측정한 흔들림의 양을 시간에 따라 기록한 것 | P1-0 §1 |
| 시간파형 (time waveform) | — | 가로 시간, 세로 측정값인 그래프 | P1-0 §1 |
| 변위 / 속도 / 가속도 | d [µm], v [mm/s], a [m/s², g] | 진동을 재는 세 양. 서로 미분·적분 관계 | P1-0 §1 |
| 정현파 | A·cos(2πft + φ) | 진폭·주파수·위상 세 숫자로 정해지는 가장 기본 진동 | P1-0 §2 |
| 진폭 | A | 중심에서 꼭대기까지의 높이 (이 사이트 기본은 Peak) | P1-0 §2 |
| 주기 | T [s] | 한 번 반복하는 데 걸리는 시간 | P1-0 §2 |
| 주파수 | f [Hz] | 1초에 반복하는 횟수, f = 1/T | P1-0 §2 |
| 각주파수 | ω [rad/s] | ω = 2πf | P1-0 §2 |
| 위상, 위상차 | φ [°, rad] | 같은 주파수 정현파끼리의 시간 어긋남을 각도로 나타낸 것. 180° = 부호 반대 | P1-0 §2 |
| 회전수 | rpm | 1분당 회전 수. f [Hz] = rpm/60 | P1-0 §3 |
| 1X, nX | — | 회전 주파수, 그 n배 | P1-0 §3 |
| 차수 (order) | — | 회전 주파수의 몇 배인지로 나타낸 주파수 | P1-0 §3 |
| 서브싱크로너스 | — | 1X보다 낮은 주파수 성분 | P1-0 §3 |
| Peak (0-pk) | pk | 0에서 가장 먼 값까지의 크기 | P1-0 §4 |
| Peak-Peak | pp | 가장 큰 값 − 가장 작은 값 (정현파 = 2A) | P1-0 §4 |
| RMS (실효값) | rms | 제곱 평균의 제곱근 (정현파 = A/√2). 에너지에 비례 | P1-0 §4 |
| 평균, DC | — | 값의 평균. 주파수 0 성분 | P1-0 §4 |
| Crest factor | CF | Peak/RMS. 정현파 √2, 충격이 섞이면 커짐 | P1-0 §4 |
| 스펙트럼 | — | 가로 주파수, 세로 진폭인 신호의 성분표 | P1-0 §5 |
| FRF (구분) | — | 입력 대비 출력인 시스템의 특성. 스펙트럼과 다르다 | P1-0 §5 |
| 샘플링 | — | 일정 간격마다 신호 값을 읽어 숫자로 저장하는 것 | P1-0 §6 |
| 샘플 | x[n] | n번째로 읽은 값, x[n] = x(n/f_s) | P1-0 §6 |
| 샘플 간격 | Δt [s] | 샘플 사이의 시간 | P1-0 §6 |
| 샘플링 주파수 | f_s [Hz] | 1초에 읽는 횟수, f_s = 1/Δt | P1-0 §6 |
| 샘플 수 | N | 한 번에 모은 샘플 개수 | P1-0 §6 |
| 측정 시간 (프레임 길이) | T [s] | T = N/f_s | P1-0 §6 |
| 나이퀴스트 주파수 | f_N = f_s/2 | 샘플링으로 제대로 볼 수 있는 최고 주파수 (소개) | P1-0 §6 → 자세히 P1-2 |
| 에일리어싱 | — | f_N을 넘는 성분이 다른 주파수로 보이는 현상 (소개) | P1-0 §6 → 자세히 P1-2 |
| 분해능 | Δf [Hz] | 스펙트럼 주파수 눈금 간격, Δf = 1/T (소개) | P1-0 §6 → P1-1 §5, 자세히 P1-3 |
| 기본파 | f₀ | 주기 신호 전체가 반복되는 주파수 = 1/T | P1-1 §2 |
| 하모닉 (고조파), n차 | — | 기본파의 정수배 주파수 성분 | P1-1 §2 |
| 푸리에 급수 | — | 주기 신호 = 기본파와 하모닉의 합 | P1-1 §2 |
| 진폭 스펙트럼 / 위상 스펙트럼 | Aₙ / φₙ | 성분별 진폭 / 위상을 주파수에 대해 그린 것 | P1-1 §2 |
| 오버슈트 (깁스 현상) | — | 날카로운 모서리를 정현파로 만들 때 남는 약 9 % 뿔 | P1-1 §2 (랩 과제) |
| 직교성 | — | 서로 다른 주파수 정현파를 곱해 평균 내면 0 | P1-1 §2 |
| Parseval | — | RMS² = 성분별 RMS²의 합. 에너지는 진폭만으로 정해짐 | P1-1 §2 |
| 템플릿 (상관) | — | 신호에 곱해서 더해 보는 기준 정현파 | P1-1 §3 |
| DFT | X[k] | 각 주파수 템플릿과 곱해서 더한 값의 모음 | P1-1 §3 |
| 실수부 / 허수부 | Re, Im | cos 템플릿 쪽 합 / sin 템플릿 쪽 합(부호 반대) | P1-1 §3 |
| bin | k | FFT가 계산하는 정수 주파수 칸. f_k = k·f_s/N | P1-1 §3 |
| 누설 (소개) | — | bin 사이 성분이 여러 bin에 퍼지는 현상 | P1-1 §3 → 자세히 P1-4 |
| 양측 / 단일측 스펙트럼 | — | ±f 양쪽에 A/2씩 / 0~f_s/2만 보이고 진폭 2배 | P1-1 §4 |
| 제로패딩 | — | 샘플 뒤에 0을 붙여 FFT를 키우는 것. 보간일 뿐 분해능은 그대로 | P1-1 §5 |
| FFT | — | DFT를 빠르게 계산하는 알고리즘 (같은 값) | P1-1 §6 |
