# Glossary — 용어집

> 사이트에 나오는 용어와 **처음 설명하는 페이지**를 모은다 (D-024, D-026 개념 순서 규칙). 페이지를 쓸 때 이 표로 "이 용어가 앞 페이지에서 설명됐나"를 대조한다.
> - 새 용어를 쓰면: 그 페이지 안에서 정의하고 여기에 한 줄 추가한다.
> - 앞 페이지에서 설명된 용어를 쓰면: 필요하면 "(P1-0 §4)"처럼 위치만 밝힌다.
> - "처음 나오는 곳"보다 앞 페이지에서는 그 용어를 쓰지 않는다. 꼭 필요하면 한 줄 설명 + "(P1-x에서 자세히)".
> 나중에 사이트의 용어집 페이지(REF-2)로 보여준다.

| 주파수 | f [Hz] | 1초에 반복하는 횟수, f = 1/T | P1-0 §2 |
| 각주파수 | ω [rad/s] | ω = 2πf | P1-0 §2 |
| 위상, 위상차 | φ [°, rad] | 같은 주파수 정현파끼리의 시간 어긋남을 각도로 나타낸 것. 180° = 부호 반대 | P1-0 §2 |
| 회전수 | rpm | 1분당 회전 수. f [Hz] = rpm/60 | P1-0 §3 |
| 1X, nX | — | 회전 주파수, 그 n배 | P1-0 §3 |
| 차수 (order) | — | 회전 주파수의 몇 배인지로 나타낸 주파수 | P1-0 §3 |

| RMS (실효값) | rms | 제곱 평균의 제곱근 (정현파 = A/√2). 에너지에 비례 | P1-0 §4 |
| 평균, DC | — | 값의 평균. 주파수 0 성분 | P1-0 §4 |
| Crest factor | CF | Peak/RMS. 정현파 √2, 충격이 섞이면 커짐 | P1-0 §4 |
| 스펙트럼 | — | 가로 주파수, 세로 진폭인 신호의 성분표 | P1-0 §5 |
| FRF (구분) | — | 입력 대비 출력인 시스템의 특성. 스펙트럼과 다르다 | P1-0 §5 |
| 샘플링 | — | 일정 간격마다 신호 값을 읽어 숫자로 저장하는 것 | P1-0 §6 |
| 샘플 | x[n] | n번째로 읽은 값, x[n] = x(n/f_s) | P1-0 §6 |
| 샘플 간격 | Δt [s] | 샘플 사이의 시간 | P1-0 §6 |
| 샘플링 주파수 | f_s [Hz] | 1초에 읽는 횟수, f_s = 1/Δt | P1-0 §6 |
| 샘플 수 | N | 한 번에 모은 샘플 개수 | P1-0 §6 |
| 측정 시간 (프레임 길이) | T [s] | T = N/f_s | P1-0 §6 |
| 나이퀴스트 주파수 | f_N = f_s/2 | 샘플링으로 제대로 볼 수 있는 최고 주파수 (소개) | P1-0 §6 → 자세히 P1-2 |
| 에일리어싱 | — | f_N을 넘는 성분이 다른 주파수로 보이는 현상 (소개) | P1-0 §6 → 자세히 P1-2 |
| 분해능 | Δf [Hz] | 스펙트럼 주파수 눈금 간격, Δf = 1/T = f_s/N (소개) | P1-0 §6 → bin 간격 P1-1 §2.1, 자세히 P1-3 |
| 주기 신호 | T₀ [s] | 같은 모양이 T₀마다 되풀이되는 신호 | P1-1 §1.1 |
| 기본파, 기본 주파수 | f₀ = 1/T₀ | 주기 신호가 되풀이되는 주파수 | P1-1 §1.1 |
| 하모닉 (고조파), n차 | n·f₀ | 기본파의 정수배 주파수 성분. 회전기계에서 f₀ = 1X이면 2X, 3X … | P1-1 §1.1 |
| 푸리에 급수 | — | 주기 신호 = 평균 + 기본파 + 하모닉의 합 | P1-1 §1.1 |
| 깁스 현상 (오버슈트) | — | 모서리를 정현파로 만들 때 남는 약 9 % 뿔. 차수를 늘려도 폭만 좁아짐 | P1-1 §1.2 |
| 진폭 스펙트럼 / 위상 스펙트럼 | Aₙ / φₙ | 성분별 진폭 / 위상을 주파수에 대해 그린 것. 진폭 스펙트럼은 위상을 버린다 | P1-1 §1.3 |
| 직교 | — | 서로 다른 주파수 정현파를 곱해 평균 내면 0 | P1-1 §1.3 |
| 파스발 정리 | — | RMS² = 성분별 RMS²의 합. RMS는 진폭만으로 정해짐 | P1-1 §1.3 |
| 펄스 폭 ↔ 스펙트럼 폭 | τ, 1/τ | 시간에서 짧을수록 주파수에서 넓다 (첫 0점 1/τ) | P1-1 §1.4 |
| 상관, 템플릿 | — | 기준 정현파를 샘플마다 곱해 더해서 "얼마나 닮았나"를 재는 것 | P1-1 §2.1 |
| bin | k, f_k = k/T | T 안에 정확히 k번 반복하는 템플릿 / 그 결과 막대. 간격 Δf | P1-1 §2.1 |
| DFT | X[k] | bin마다 cos·sin 템플릿과 곱해서 더한 값. A_k = 2∣X[k]∣/N | P1-1 §2.2 |
| 실수부 / 허수부 | Re, Im | cos 템플릿 쪽 합 / sin 템플릿 쪽 합(부호 반대) | P1-1 §2.2 |
| 누설 (소개) | — | bin 사이 성분이 여러 bin에 퍼지고 피크가 낮아지는 현상 | P1-1 §2.2 → 자세히 P1-4 §1 |
| 음의 주파수 | −f | 정현파를 반대로 도는 두 회전 화살표로 쓸 때 시계 방향 쪽 | P1-1 §3 |
| 양측 / 단일측 스펙트럼 | — | ±f에 A/2씩 / 0~f_s/2만, 진폭 2배 (0 Hz·f_s/2 제외) | P1-1 §3 |
| 제로패딩 | N_FFT | 샘플 뒤에 0을 붙여 FFT를 키우는 것. 촘촘히 그리는 보간일 뿐 분해능은 그대로 | P1-1 §4 |

| 메인로브 / 사이드로브 | — | 윈도우 스펙트럼의 중심 주 엽(분해능) / 주변 부 엽 날개(동적범위) | P1-4 §3 |

| 에너지 보정 계수 (ECF) | √(N/S₂) | 윈도우로 줄어든 광대역 랜덤 잡음·파워·RMS의 에너지 복원 계수 | P1-4 §5 |
