# Glossary — 용어집

> 사이트에 나오는 용어와 **처음 설명하는 페이지**를 모은다 (D-024, D-026 개념 순서 규칙). 페이지를 쓸 때 이 표로 "이 용어가 앞 페이지에서 설명됐나"를 대조한다.
> - 새 용어를 쓰면: 그 페이지 안에서 정의하고 여기에 한 줄 추가한다.
> - 앞 페이지에서 설명된 용어를 쓰면: 필요하면 "(P1-0 §4)"처럼 위치만 밝힌다.
> - "처음 나오는 곳"보다 앞 페이지에서는 그 용어를 쓰지 않는다. 꼭 필요하면 한 줄 설명 + "(P1-x에서 자세히)".
> 나중에 사이트의 용어집 페이지(REF-2)로 보여준다.

| 용어 | 기호·단위 | 한 줄 뜻 | 처음 나오는 곳 |
|---|---|---|---|
| 진동 (Vibration) | — | 평형 위치를 사이에 두고 되풀이되는 왕복 운동 | P0-1 §1 |
| 평형 위치 (Equilibrium position) | x = 0 | 힘이 균형을 이루어 가만히 있을 수 있는 자리 | P0-1 §1 |
| 변위 (Displacement) | x(t) [m] | 평형 위치에서 어느 방향으로 얼마나 벗어났는지 | P0-1 §1 |
| 복원력 (Restoring force) | F = −kx [N] | 물체를 평형 위치로 되돌리려는 힘 | P0-1 §2 |
| 강성 (Stiffness) | k [N/m] | 변위 1 m당 생기는 복원력, 물체나 지지가 얼마나 단단한지 | P0-1 §2 |
| 관성 (Inertia) | m [kg] | 움직이던 물체가 그 움직임을 이어 가려는 성질 | P0-1 §3 |
| 속도 (Velocity) | v [m/s] | 위치가 변하는 빠르기. 끝점에서 0, 평형점에서 크기가 최대 | P0-1 §3 |
| 끝점 | x = ±A | 왕복 운동에서 평형 위치로부터 가장 멀리 벗어난 자리 | P0-1 §3 |
| 에너지 | [J] | 움직임이나 변형으로 일을 할 수 있는 정도 | P0-1 §4 |
| 질량-스프링 모델 (Mass-Spring Model) | m, k | 움직이는 질량과 되돌리는 강성만 남겨 진동계를 단순화한 모델 | P0-1 §6 |
| 운동방정식 (Equation of Motion) | mẍ + kx = 0 | 물체에 걸린 힘과 그 결과인 움직임을 잇는 식 | P0-2 §1 |
| 가속도 (Acceleration) | a = ẍ [m/s²] | 속도가 변하는 빠르기. 질량-스프링 끝점에서 크기가 최대 | P0-2 §1 |
| 정현파 (Sinusoid) | A·cos(2πft + φ) | 진폭·주파수·위상 세 숫자로 정해지는 매끈한 반복 파형 | P0-2 §2 |
| 진폭 (Amplitude) | A | 중심에서 꼭대기까지의 높이 (이 사이트 기본은 Peak) | P0-2 §2 |
| 주파수 (Frequency) | f [Hz] | 1초에 반복하는 횟수, f = 1/T | P0-2 §2 |
| 각주파수 (Angular frequency) | ω [rad/s] | 한 번의 왕복을 2π rad로 나타낸 주파수, ω = 2πf | P0-2 §2 |
| 위상, 위상차 (Phase) | φ [°, rad] | 같은 주파수 정현파끼리의 시작 시점 어긋남. 180° = 부호 반대 | P0-2 §2 |
| 고유진동수 (Natural frequency) | fₙ [Hz] | 계가 외부의 반복 힘 없이 자유롭게 흔들리는 고유한 박자 | P0-2 §3 |
| 초기조건 (Initial conditions) | x₀, v₀ | 움직임을 시작하는 순간의 위치와 속도 | P0-2 §5 |
| 정적 처짐 (Static deflection) | δₛₜ [m] | 일정한 무게를 받았을 때 평형 위치가 내려간 양 | P0-2 §7.1 |
| 감쇠 (Damping) | — | 진동 에너지를 열 등으로 바꾸어 진폭을 줄이는 작용 | P0-3 §1 |
| 점성 감쇠 (Viscous damping) | F_c = −cẋ | 속도에 비례하고 움직임과 반대 방향인 감쇠 모델 | P0-3 §1 |
| 감쇠 계수 (Damping coefficient) | c [N·s/m] | 점성 감쇠력의 크기를 정하는 비례 계수 | P0-3 §1 |
| 임계감쇠 계수 | c_c = 2√(km) | 진동 없이 가장 빠르게 복귀하는 경계의 감쇠 계수 | P0-3 §2 |
| 감쇠비 (Damping ratio) | ζ = c/c_c | 현재 감쇠를 임계감쇠와 비교한 단위 없는 비 | P0-3 §2 |
| 부족감쇠 (Underdamped) | 0 < ζ < 1 | 평형을 지나 왕복하며 진폭이 줄어드는 상태 | P0-3 §2 |
| 임계감쇠 (Critically damped) | ζ = 1 | 평형을 넘지 않고 가장 빠르게 복귀하는 상태 | P0-3 §2 |
| 과감쇠 (Overdamped) | ζ > 1 | 평형을 넘지 않지만 임계감쇠보다 느리게 복귀하는 상태 | P0-3 §2 |
| 포락선 (Envelope) | ±Ae^(−ζωₙt) | 감쇠 진동 파형의 바깥쪽 꼭대기를 잇는 경계 | P0-3 §3 |
| 감쇠 고유진동수 | ω_d [rad/s] | 부족감쇠계가 실제로 왕복하는 각주파수 | P0-3 §4 |
| 대수감쇠율 (Logarithmic decrement) | δ = ln(x_i/x_{i+1}) | 한 주기 떨어진 같은 방향 피크가 줄어든 정도 | P0-3 §5 |
| 가진력 (Excitation force) | F₀ cos ωt [N] | 계를 흔들도록 바깥에서 계속 가하는 힘 | P0-4 §1 |
| 강제진동 (Forced vibration) | — | 바깥 힘(가진력)을 계속 받아 일어나는 진동 | P0-4 §1 |
| 과도 응답 (Transient response) | — | 외력이 시작될 때 계 고유의 박자로 흔들리다 감쇠로 사라지는 부분 | P0-4 §2 |
| 정상상태 응답 (Steady-state response) | x(t) = X cos(ωt − φ) | 과도가 사라진 뒤 힘과 같은 박자로 계속 남는 응답 | P0-4 §2 |
| 위상 지연 (Phase lag) | φ [°, rad] | 정상상태 변위가 가진력보다 시간적으로 늦은 각도 (0°~180°) | P0-4 §2 |
| 진동수비 (Frequency ratio) | r = ω/ωₙ = f/fₙ | 가진 주파수와 계의 고유진동수의 비 | P0-4 §3 |
| 공진 (Resonance) | r ≈ 1 | 힘의 박자가 고유진동수와 맞아 진폭이 크게 증폭되는 현상 | P0-4 §4 |
| Q 값 (Q factor) | Q ≈ 1/(2ζ) | 공진 시 정적 처짐에 대한 증폭 배율 | P0-4 §4 |
| Half-power 폭 | Δr ≈ 2ζ, Δf ≈ 2ζ fₙ | 진폭이 공진 피크의 1/√2가 되는 두 점 사이의 주파수 폭 | P0-4 §4 |
| 주파수응답 함수 (FRF) | H(ω) | 입력 힘 1에 대한 출력 응답의 크기와 위상을 주파수마다 나타낸 계의 성질 | P0-4 §5 |
| Bode 선도 (Bode plot) | — | FRF의 진폭비 곡선과 위상 곡선을 위아래로 함께 나타낸 그림 | P0-4 §5 |
| 맥놀이 (Beat) | — | 박자가 가까운 두 진동 성분이 겹쳐 진폭이 주기적으로 커졌다 작아지는 현상 | P0-4 §6 |
| 진동 신호 | — | 센서가 측정한 흔들림의 양을 시간에 따라 기록한 것 | P1-0 §1 |
| 시간파형 (time waveform) | — | 가로 시간, 세로 측정값인 그래프 | P1-0 §1 |
| 주기 (Period) | T [s] | 같은 상태로 돌아오는 한 번의 왕복 시간 | P0-1 §4 |
| 회전수 | rpm | 1분당 회전 수. f [Hz] = rpm/60 | P1-0 §3 |
| 1X, nX | — | 회전 주파수, 그 n배 | P1-0 §3 |
| 차수 (order) | — | 회전 주파수의 몇 배인지로 나타낸 주파수 | P1-0 §3 |
| 서브싱크로너스 | — | 1X보다 낮은 주파수 성분 | P1-0 §3 |
| Peak (0-pk) | pk | 0에서 가장 먼 값까지의 크기 | P1-0 §4 |
| Peak-Peak | pp | 가장 큰 값 − 가장 작은 값 (정현파 = 2A) | P1-0 §4 |
| RMS (실효값) | rms | 제곱 평균의 제곱근 (정현파 = A/√2). 에너지에 비례 | P1-0 §4 |
| 평균, DC | — | 값의 평균. 주파수 0 성분 | P1-0 §4 |
| Crest factor | CF | Peak/RMS. 정현파 √2, 충격이 섞이면 커짐 | P1-0 §4 |
| 스펙트럼 | — | 가로 주파수, 세로 진폭인 신호의 성분표 | P1-0 §5 |
| FRF (구분) | — | 입력 대비 출력인 시스템의 특성. 스펙트럼과 다르다 | P1-0 §5 |
| 샘플링 | — | 일정 간격마다 신호 값을 읽어 숫자로 저장하는 것 | P1-0 §6 |
| 샘플 | x[n] | n번째로 읽은 값, x[n] = x(n/f_s) | P1-0 §6 |
| 샘플 간격 | Δt [s] | 샘플 사이의 시간 | P1-0 §6 |
| 샘플링 주파수 | f_s [Hz] | 1초에 읽는 횟수, f_s = 1/Δt | P1-0 §6 |
| 샘플 수 | N | 한 번에 모은 샘플 개수 | P1-0 §6 |
| 측정 시간 (프레임 길이) | T [s] | T = N/f_s | P1-0 §6 |
| 나이퀴스트 주파수 | f_N = f_s/2 | 샘플링으로 제대로 볼 수 있는 최고 주파수 (소개) | P1-0 §6 → 자세히 P1-2 §1.3 |
| 에일리어싱 | — | f_N을 넘는 성분이 다른 주파수로 보이는 현상 (소개) | P1-0 §6 → 자세히 P1-2 §1.1 |
| 분해능 | Δf [Hz] | 스펙트럼 주파수 눈금 간격, Δf = 1/T = f_s/N (소개) | P1-0 §6 → bin 간격 P1-1 §2.1, 자세히 P1-3 §1 |
| 주기 신호 | T₀ [s] | 같은 모양이 T₀마다 되풀이되는 신호 | P1-1 §1.1 |
| 기본파, 기본 주파수 | f₀ = 1/T₀ | 주기 신호가 되풀이되는 주파수 | P1-1 §1.1 |
| 하모닉 (고조파), n차 | n·f₀ | 기본파의 정수배 주파수 성분. 회전기계에서 f₀ = 1X이면 2X, 3X … | P1-1 §1.1 |
| 푸리에 급수 | — | 주기 신호 = 평균 + 기본파 + 하모닉의 합 | P1-1 §1.1 |
| 깁스 현상 (오버슈트) | — | 모서리를 정현파로 만들 때 남는 약 9 % 뿔. 차수를 늘려도 폭만 좁아짐 | P1-1 §1.2 |
| 진폭 스펙트럼 / 위상 스펙트럼 | Aₙ / φₙ | 성분별 진폭 / 위상을 주파수에 대해 그린 것. 진폭 스펙트럼은 위상을 버린다 | P1-1 §1.3 |
| 직교 | — | 서로 다른 주파수 정현파를 곱해 평균 내면 0 | P1-1 §1.3 |
| 파스발 정리 | — | RMS² = 성분별 RMS²의 합. RMS는 진폭만으로 정해짐 | P1-1 §1.3 |
| 펄스 폭 ↔ 스펙트럼 폭 | τ, 1/τ | 시간에서 짧을수록 주파수에서 넓다 (첫 0점 1/τ) | P1-1 §1.4 |
| 상관, 템플릿 | — | 기준 정현파를 샘플마다 곱해 더해서 "얼마나 닮았나"를 재는 것 | P1-1 §2.1 |
| bin | k, f_k = k/T | T 안에 정확히 k번 반복하는 템플릿 / 그 결과 막대. 간격 Δf | P1-1 §2.1 |
| DFT | X[k] | bin마다 cos·sin 템플릿과 곱해서 더한 값. A_k = 2∣X[k]∣/N | P1-1 §2.2 |
| 실수부 / 허수부 | Re, Im | cos 템플릿 쪽 합 / sin 템플릿 쪽 합(부호 반대) | P1-1 §2.2 |
| 누설 (소개) | — | bin 사이 성분이 여러 bin에 퍼지고 피크가 낮아지는 현상 | P1-1 §2.2 → 자세히 P1-4 §1 |
| 음의 주파수 | −f | 정현파를 반대로 도는 두 회전 화살표로 쓸 때 시계 방향 쪽 | P1-1 §3 |
| 양측 / 단일측 스펙트럼 | — | ±f에 A/2씩 / 0~f_s/2만, 진폭 2배 (0 Hz·f_s/2 제외) | P1-1 §3 |
| 제로패딩 | N_FFT | 샘플 뒤에 0을 붙여 FFT를 키우는 것. 촘촘히 그리는 보간일 뿐 분해능은 그대로 | P1-1 §4 |
| 둔덕 폭 (직사각형) | ≈ 2/T | T초 동안 잰 정현파 하나가 스펙트럼에서 차지하는 폭(0점 사이) | P1-1 §4 |
| FFT | — | DFT와 같은 결과를 N log₂N 계산으로 내는 알고리즘 | P1-1 §5 |
| 에일리어스 주파수 | f_a = ∣f − k·f_s∣ | 접혀서 보이는 가짜 주파수, k = round(f/f_s) | P1-2 §1.2 |
| 샘플링 정리 | f < f_N | 제 주파수로 보이려면 f_s > 2f. 딱 f_N이면 위상에 따라 사라짐 | P1-2 §1.3 |
| F_max (분석 최대 주파수) | F_max [Hz] | 분석기가 화면에 보여 주는 최고 주파수 | P1-2 §2.1 |
| AAF (안티에일리어싱 필터) | — | 샘플링 전에 F_max 위 성분을 깎는 아날로그 필터 | P1-2 §2.1 |
| dB (데시벨) | 20 log₁₀ r | 두 진폭의 비를 로그로 나타낸 값. −20 dB = 1/10 | P1-2 §2.2 |
| 필터 차수 | — | 클수록 차단 주파수 위를 가파르게 깎음 (Butterworth n차: 주파수 2배마다 약 −6n dB) | P1-2 §2.2 |

| 맥놀이 (Beat) | 주기 1/∣f₂ − f₁∣ | 가까운 두 정현파의 합이 천천히 출렁이는 것. 차이를 알아보려면 그 주기만큼 봐야 함 | P1-3 §1 |
