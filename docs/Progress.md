## 핸드오프 (다음 작업자에게)

- **작성 기준은 Contents §1 (D-025 톤 + D-026 구조)**. 핵심: 앞 페이지까지 나온 개념만 쓴다(개념 척추 표 §1-2), 개념마다 예시 그림(`Figure`), 강조 상자는 `Callout` 6종, 랩 앞 "따라 하기"·뒤 해석, **코드 블록·아스키 도표 금지**(사용자: CLI 같은 느낌이 싫다), 정리는 카드형 표.
- **그림**: `src/figures/p{Part}-{절}.ts`에서 `lib/dsp`로 계산 → `Figure.astro`가 빌드 시 SVG. 기준 폭 900, 패널 height는 680 기준 값에 1.2배가 곱해진다. 새 그림은 `/dev/figures/`(id 순)에서 겹침 확인. 스펙트럼 그림은 분석기처럼 Hann으로 계산해야 실제 화면과 맞는 경우가 많다 (P1-3).
- **폭**: 절 페이지의 글·그림·상자·랩은 모두 `--content-width`(920px). 랩 수식·읽음값은 위아래로 쌓인다.
- **함정**: `texNumber`/`formatNumber` 둘째 인자는 유효숫자. 이론상 0인 값은 0으로 정리(hydration). MDX에서 문장부호로 끝나는 굵은 글씨 + 한글은 `<strong>`, 표 안 수식에 `|` 금지. bash heredoc은 백슬래시를 먹으므로 TS·TeX가 든 스크립트는 Write 도구로 만든다.
- **다음 작업**: 사용자가 P1-0 ~ P1-3을 확인한 뒤 P1-4(윈도우)·P1-5(평균화, `AveragingLab` 연결) 개편. P1-4는 코드 블록만 교체한 상태이고, P1-5는 Codex의 D-024 검토안(건조한 문체) 그대로다.
