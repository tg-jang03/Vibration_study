## 0. 재구성 원칙

1. **의존성 순서**: 뒤 절은 앞 절의 개념과 랩만으로 이해할 수 있어야 한다.
2. **진동의 물리부터 (D-027)**: Part 0은 진동을 처음 배우는 사람을 위한 출발점이다. 고교 물리(F = ma)와 "미분 = 변화율"만으로 복원력·관성 → 고유진동수 → 감쇠 → 강제진동·공진 → 모드 → 불평형과 1X → 응답에서 원인으로까지 간다. Part 0은 물리(왜·어떻게 흔들리나, 원인 → 응답), Part 1은 측정·신호(그 흔들림을 어떻게 재고 나눠 보나)를 맡는다. 회전체 동역학(Bode/AF, Jeffcott, 유막 안정성)은 Part 4로 따로 두어 현장 플롯 읽기(Part 5) 바로 앞에 놓는다.
3. **신호처리는 두 단계**: 분석기 설정의 기초(Part 1) → 센서와 측정 체인(Part 2) → 숨은 신호를 꺼내는 확장 기법(Part 3). 실제로 어떻게 측정되는지 알고 나서 고급 기법으로 간다.
4. **결함은 두 관점**: 메커니즘별(Part 6)과 GT/ST 운전 상황별(Part 7).
5. **원본 Phase 10(심화)은 제외**: 로터다이나믹스 기초만 Part 4에 흡수하고, ML·AE·상용 CMS 툴 숙달은 범위에서 뺀다.
6. **마지막은 종합 진단 연습**(Part 10): 숨은 결함이 있는 가상 기계를 스스로 진단한다.
7. **모든 진단은 "증거 5요소"로**: 주파수(몇 X) · 진폭 · 위상 · 방향(수평/수직/축방향, 정/역 프리세션) · 운전조건 의존성(속도·부하·온도·시간). 0-7에서 "원인을 알고 응답을 예측하던 문제를 거꾸로 푸는 것이 진단"이라는 흐름 속에 소개하고, 이후 모든 절에서 이 틀을 쓴다.

## Part 0. 진동의 기초: 기계는 왜, 어떻게 흔들리나

독자 기준: 고교 물리(F = ma)와 "미분 = 변화율" 정도만 가정한다. 식을 쓰되 "무엇이 무엇을 정하나"를 말로 먼저 풀고, 그림과 미니 랩으로 확인한다. 각 절은 생활 속 질문에서 출발해 Part 1의 어느 내용으로 이어지는지 밝히며 끝난다 (D-027).

### 0-1 진동이란: 평형 · 복원력 · 관성 (신규)
- **목표**
  - 진동을 "평형 위치를 사이에 두고 되풀이되는 왕복 운동"으로 설명할 수 있다.
  - 복원력과 관성이 번갈아 일해서 왕복이 계속되는 과정을 말로 설명할 수 있다.
  - 변위 x(t) 그래프에서 끝점·평형점·주기를 읽을 수 있다.
- **내용**
  - 여는 질문: 책상 끝에 자를 눌러 놓고 튕기면, 왜 한 번 휘고 멈추지 않고 한동안 계속 떨릴까?
  - 평형 위치: 힘이 균형을 이뤄 가만히 있을 수 있는 자리. 진동은 이 자리를 사이에 둔 왕복이다.
  - 복원력: 평형에서 벗어난 만큼 되돌리려는 힘 (스프링, 자의 탄성). 많이 벗어날수록 크다 → F = −kx (k: 강성, 단단한 정도).
  - 관성: 움직이던 물체는 계속 움직이려 한다 (F = ma의 m). 평형 위치로 돌아왔을 때 속도가 남아 있어서 그대로 지나친다.
  - 한 번의 왕복: 끝(가장 많이 벗어난 곳)에서 잠깐 멈춤 → 복원력에 끌려 되돌아옴 → 평형에서 가장 빠름 → 반대쪽 끝에서 다시 멈춤. 에너지는 스프링(위치 에너지)과 질량(운동 에너지) 사이를 오간다.
  - 변위 x(t): 평형에서 얼마나 벗어났는지를 시간에 따라 그린 그래프. 한 번 왕복하는 데 걸리는 시간이 주기 T.
  - 질량-스프링 모델: 자·그네·기초 위의 펌프처럼 모양은 달라도 "움직이는 질량(관성) + 되돌리는 스프링(복원력)"으로 단순화하면 같은 방식으로 흔들린다.
  - Part 1 연결: 센서가 기록하는 것이 이 x(t)(또는 그 변화율인 속도·가속도)다 → P1-0의 시간파형.
- **수식**: 복원력 `F = -kx` (훅의 법칙), 뉴턴 제2법칙 `F = ma`. 둘을 합쳐 운동방정식을 세우는 것은 0-2.
- **랩**: LAB-MCK-01 질량-스프링 자유진동 (기본 모드) — 질량을 당겼다 놓으면 위에는 질량이 움직이고, 아래에는 같은 시각까지의 x(t)가 그려진다. 끝점·평형점 표시
- **과제**: 끝점에서 속도는? 평형점에서는? 더 무거운 질량이면 왕복이 빨라질까 느려질까? (예측만 하고 0-2에서 확인)
- **함정**: 진동은 무언가가 계속 밀어 줘야 생긴다고 생각한다 (한 번 건드리면 복원력과 관성만으로 계속된다). 변위가 0인 순간을 멈춘 순간으로 착각한다 (평형점에서 가장 빠르다).
- **원본**: 없음 (원본 Phase 0이 전제로 둔 진동 입문)

### 0-2 고유진동수: 물체마다 정해진 박자 (신규)
- **목표**
  - F = ma와 복원력으로 운동방정식 m ẍ + kx = 0을 세우고, 그 해가 정현파라는 것을 설명할 수 있다.
  - 정현파를 진폭 A · 주파수 f · 위상 φ로 읽고, ω = 2πf, T = 1/f를 오갈 수 있다.
  - 고유진동수 f_n = √(k/m)/2π를 계산하고, m·k가 바뀔 때 어떻게 변하는지 예측할 수 있다.
  - 변위·속도·가속도의 진폭과 위상 관계를 설명할 수 있다.
- **내용**
  - 여는 질문: 기타 줄, 종, 자는 왜 저마다 정해진 박자로 울릴까? 세게 튕겨도 박자가 그대로인 이유는?
  - 운동방정식: 질량에 걸리는 힘은 복원력 −kx뿐이다 → m ẍ = −kx → m ẍ + kx = 0. ẋ는 변위의 변화율(속도 v), ẍ는 속도의 변화율(가속도 a).
  - 해: "두 번 미분하면 자기 자신의 −k/m배가 되는 함수"를 찾는 문제 → 정현파 x(t) = A cos(ω_n t + φ).
  - 정현파의 세 숫자: 진폭 A(얼마나 크게), 주파수 f(1초에 몇 번, 주기 T = 1/f), 위상 φ(언제 시작했나). 각주파수 ω = 2πf [rad/s]는 "1초에 도는 각도"로 쓴 주파수.
  - 고유진동수: ω_n = √(k/m), f_n = ω_n/2π. 무거우면 느리고 단단하면 빠르다. 진폭과 무관해서 "정해진 박자"다.
  - 초기조건(처음 위치 x₀, 처음 속도 v₀)은 A와 φ만 정한다. f_n은 m과 k만으로 정해진다.
  - 어림 공식(맛보기): 자기 무게로 처진 양 δ_st만 알아도 f_n = (1/2π)√(g/δ_st) (k·δ_st = m·g이므로).
  - 변위·속도·가속도: 정현파면 속도 진폭 = ωA, 가속도 진폭 = ω²A이고 위상은 차례로 90°씩 앞선다. 끝점에서 v = 0이고 가속도 크기가 최대(평형 쪽을 향함), 평형점에서 속도 크기가 최대이고 a = 0. a = −ω_n² x.
  - Part 1 연결: P1-0의 정현파 읽기(A·f·φ, 위상차)와 변위·속도·가속도 (주파수에 따른 환산 v = 2πf·d는 P1-6).
- **수식**: `m\ddot x + kx = 0`, `x(t) = A\cos(\omega_n t + \phi)`, `\omega_n = \sqrt{k/m},\quad f_n = \dfrac{\omega_n}{2\pi}`, `\omega = 2\pi f,\quad T = 1/f`, `A = \sqrt{x_0^2 + (v_0/\omega_n)^2}`, `v = -\omega A\sin(\omega t + \phi),\quad a = -\omega^2 x`
- **랩**: LAB-MCK-01 (m · k · x₀ · v₀ 조작, x·v·a 동시 표시, f_n 읽음값), LAB-BAS-01 정현파의 세 숫자 (M2.2에서 P1-0에서 옮겨 옴)
- **과제**: m = 1 kg, k = 1000 N/m면 f_n은? (≈ 5.03 Hz) m을 4배로 하면? (절반) k를 4배로 하면? (2배) 두 배 세게 튕기면? (그대로) 끝점과 평형점에서 v와 a는 각각?
- **함정**: 크게 흔들리면 박자도 빨라진다고 생각한다 (선형계에서는 진폭과 무관). 변위·속도·가속도가 같은 순간에 최대가 된다고 생각한다.
- **원본**: Phase 0 대응표의 "Natural frequency" (기초 개념만)

### 0-3 감쇠: 흔들림은 왜 잦아드나 (신규)
- **목표**
  - 감쇠가 진동 에너지를 빼앗아 진폭이 지수적으로 줄어든다는 것을 설명할 수 있다.
  - 감쇠비 ζ, 포락선 e^{−ζω_n t}, 감쇠 고유진동수 ω_d를 계산할 수 있다.
  - 파형의 연속 피크 비(대수감쇠율)로 ζ를 어림할 수 있다.
- **내용**
  - 여는 질문: 종을 치면 소리는 왜 점점 작아지다 사라질까? 자동차의 쇼크업소버는 무엇을 할까?
  - 감쇠(Damping): 움직임을 방해해 진동 에너지를 열로 바꾸는 것 (공기 저항, 재료 내부 마찰, 기름·유체). 가장 단순한 모델은 속도에 비례하는 힘 −c ẋ (점성 감쇠, c: 감쇠 계수).
  - 운동방정식 m ẍ + c ẋ + kx = 0. 감쇠의 크기는 감쇠비 ζ = c/(2√(km))로 비교한다 (ζ = 1이면 임계감쇠).
  - ζ < 1(부족감쇠): 진동하면서 포락선 A e^{−ζω_n t}를 따라 줄어든다. 기계 구조물은 대부분 이 경우이고 ζ가 수 % 이하인 경우가 많다.
  - ζ ≥ 1(임계·과감쇠): 진동하지 않고 평형으로 돌아온다 (문 닫힘 장치).
  - 감쇠 고유진동수 ω_d = ω_n √(1 − ζ²): 작은 ζ에서는 ω_n과 거의 같다 (ζ = 0.05면 0.13 % 차이) → 감쇠는 박자보다 "얼마나 오래 울리나"를 정한다.
  - 대수감쇠율(Logarithmic decrement, 맛보기): 한 주기 뒤 피크의 비 δ = ln(x_i / x_{i+1}) ≈ 2πζ → 파형에서 ζ를 읽는다. 진폭이 절반이 되는 주기 수 ≈ 0.11/ζ.
  - Part 1 연결: 빨리 잦아드는 짧은 울림은 스펙트럼에서 넓은 둔덕이 된다 (P1-1 짧은 펄스 ↔ 넓은 스펙트럼). 임팩트 시험의 지수 윈도우는 인위적으로 감쇠를 더하므로 ζ를 보정해야 한다 (P1-4).
- **수식**: `m\ddot x + c\dot x + kx = 0`, `\zeta = \dfrac{c}{2\sqrt{km}}`, `x(t) = A e^{-\zeta\omega_n t}\cos(\omega_d t + \phi)`, `\omega_d = \omega_n\sqrt{1-\zeta^2}`, `\delta = \ln\dfrac{x_i}{x_{i+1}} = \dfrac{2\pi\zeta}{\sqrt{1-\zeta^2}} \approx 2\pi\zeta`
- **랩**: LAB-DAMP-01 감쇠 자유진동 — ζ 슬라이더 → 파형 + 포락선, 연속 피크 비 → δ → ζ 추정, 진폭이 절반이 되는 주기 수
- **과제**: ζ = 0.05에서 진폭이 절반이 되려면 몇 주기? (≈ 2.2) 연속 두 피크가 1.00 → 0.73이면 ζ는? (δ ≈ 0.315 → ζ ≈ 0.05) ζ를 1로 올리면 파형은?
- **함정**: 감쇠가 진동 주파수를 크게 바꾼다고 생각한다 (작은 ζ에서는 거의 그대로). 여러 주파수가 섞인 파형에 그대로 대수감쇠율을 적용한다 (성분을 먼저 나눠야 한다 → Part 1).
- **원본**: Phase 0 대응표의 "Damping ratio ζ" (기초 개념만. AF·Log decrement 활용은 4-1, 4-3)

### 0-4 강제진동과 공진 (신규)
- **목표**
  - 주기적인 힘을 계속 가하면 정상상태에서 가진 주파수로 흔들린다는 것을 설명할 수 있다.
  - 진동수비 r에 따른 진폭비와 위상(0° → 90° → 180°) 변화를 설명할 수 있다.
  - 공진에서 진폭이 약 1/(2ζ)배가 된다는 것과 주파수응답(FRF)의 뜻을 안다.
- **내용**
  - 여는 질문: 세탁기는 탈수가 시작될 때 왜 특정 순간에만 심하게 덜컹거리고, 더 빨라지면 오히려 조용해질까?
  - 가진력 F₀ cos ωt: 일정한 박자로 밀고 당기는 힘. 운동방정식 m ẍ + c ẋ + kx = F₀ cos ωt.
  - 응답 = 과도 응답(0-3의 감쇠 자유진동, 시간이 지나면 사라짐) + 정상상태 응답(남는 것). **정상상태 응답은 고유진동수가 아니라 가진 주파수로 흔들린다.**
  - 진동수비 r = ω/ω_n. 같은 힘을 아주 천천히 걸었을 때의 처짐 X_st = F₀/k에 대한 비 X/X_st로 크기를 본다.
  - 세 구간: r ≪ 1 — 스프링이 지배, 힘과 함께 움직임 (위상 ≈ 0°) / r ≈ 1 — 공진: 감쇠만 진폭을 제한 (위상 90° 지연) / r ≫ 1 — 질량(관성)이 지배, 진폭이 작아지고 힘과 반대로 움직임 (위상 ≈ 180°).
  - 공진 피크 ≈ 1/(2ζ) (Q factor라고도 한다). ζ = 0.05면 약 10배. 피크 폭도 ζ에 비례해 좁아진다 (Half-power 폭 ≈ 2ζ f_n, 데이터에서 뽑는 법은 4-1·8-1).
  - 주파수응답(FRF, Frequency Response Function): "입력(힘) 1에 대한 출력(응답)"을 주파수마다 그린 것. 진폭비와 위상 두 곡선으로 그리며(Bode 선도), 신호가 아니라 계(시스템)의 성질이다.
  - 공진 근처에서 가진을 갑자기 시작하면 과도 응답(고유진동수)과 정상상태 응답(가진 주파수)이 한동안 겹쳐 진폭이 천천히 출렁인다(맥놀이).
  - Part 1 연결: 스펙트럼(신호의 성분표)과 FRF(계의 성질)의 구분 (P1-0). 스펙트럼 피크의 위치는 원인(가진) 주파수, 높이는 "힘 × 그 주파수의 FRF" → 큰 피크가 큰 힘 때문인지 공진 때문인지는 따로 가려야 한다. 감쇠가 작은 날카로운 피크를 가르는 분해능 (P1-3), 맥놀이 (P1-7).
- **수식**: `m\ddot x + c\dot x + kx = F_0\cos\omega t`, 정상상태 `x = X\cos(\omega t - \phi)`, `\dfrac{X}{F_0/k} = \dfrac{1}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}`, `\phi = \operatorname{atan2}(2\zeta r,\ 1-r^2)`, `r = \omega/\omega_n`, 공진 `X/X_{st} \approx 1/(2\zeta)`
- **랩**: LAB-FRC-01 강제진동과 공진 — 가진 주파수 슬라이더(또는 스윕), ζ → 힘과 응답의 시간파형(과도 → 정상상태), 진폭비·위상 곡선 위의 현재 점
- **과제**: ζ = 0.05에서 r = 0.5, 1, 2의 진폭비와 위상은? (≈ 1.33·4°, 10·90°, 0.33·176°) ζ를 절반으로 하면 피크 높이와 폭은? (2배, 절반) 공진 근처에서 가진을 시작하면 처음 몇 초 동안 무엇이 보이나?
- **함정**: 진동이 크면 힘이 크다고 단정한다 (공진이면 작은 힘도 크게 증폭된다). 공진에서 위상이 0°라고 생각한다 (90° 지연). 정상상태 응답이 고유진동수로 흔들린다고 생각한다.
- **원본**: Phase 0 대응표의 "FRF", "Forced response" (기초 개념만)

### 0-5 여러 질량과 모드 (신규)
- **목표**
  - 2자유도계에 고유진동수와 모드 형상이 2개씩 있다는 것을 설명할 수 있다.
  - 실제 진동이 모드들의 합(중첩)이라는 것과, 긴 구조물(배관·축)에 고유진동수가 여러 개인 이유를 안다.
- **내용**
  - 여는 질문: 긴 배관이나 축은 왜 한 박자가 아니라 여러 박자로 떨릴까?
  - 자유도(DOF, Degree of Freedom): 움직임을 나타내는 데 필요한 좌표 수. 질량 2개를 스프링으로 이으면 2자유도.
  - 두 질량의 운동방정식이 가운데 스프링으로 서로 엮인다(연성) → 행렬로 쓰면 M ẍ + K x = 0.
  - 고유진동수가 2개, 각각에 모드 형상(Mode shape: 두 질량이 어떤 비율과 방향으로 함께 움직이나)이 하나씩: 모드 1 = 같은 방향(동상), 낮은 주파수 / 모드 2 = 반대 방향(역상), 높은 주파수.
  - 모드 형상대로 건드리면 그 모드 하나로만 흔들린다. 아무렇게나 건드리면 두 모드가 섞여 파형이 복잡해 보인다 = 정현파 두 개의 합. 가운데 스프링이 약하면 두 고유진동수가 가까워져 에너지가 두 질량 사이를 천천히 오간다.
  - 중첩(Superposition): 선형계에서는 전체 응답 = 모드별 응답의 합. 강제진동에서는 고유진동수마다 공진 피크가 생긴다.
  - 연속체(배관·축·날개): 질량과 강성이 연속으로 퍼져 있어 고유진동수와 모드가 계속 이어진다 (1차 굽힘, 2차 굽힘 …). 실제로는 관심 주파수 범위 안의 몇 개만 본다.
  - Part 1 연결: 복잡한 파형 = 정현파의 합 (P1-1 푸리에), 스펙트럼이 그 성분을 나눠 준다.
- **수식**: `\mathbf M\ddot{\mathbf x} + \mathbf K\mathbf x = \mathbf 0`, `\det(\mathbf K - \omega^2\mathbf M) = 0`. 같은 질량 m, 같은 스프링 k 세 개(벽–m–m–벽) 예: `\omega_1 = \sqrt{k/m},\ \omega_2 = \sqrt{3k/m}`, 모드 형상 [1, 1], [1, −1]
- **랩**: LAB-2DOF-01 2자유도 모드 — 가운데 스프링 강성, 초기 조건(모드 1 / 모드 2 / 한쪽만 당김) → 두 질량 애니메이션, 두 파형, 모드 형상 그림
- **과제**: 한쪽 질량만 당겼다 놓으면 두 질량은 어떻게 움직이나? 모드 2 모양으로 놓으면? 가운데 스프링을 약하게 하면 두 고유진동수는? (가까워진다)
- **함정**: 복잡한 파형을 "불규칙한 진동"으로 본다 (모드 몇 개의 합일 수 있다). 한 점만 재고 모드 형상을 판단한다 (여러 점의 위상 비교가 필요하다 → 8-1 ODS).
- **원본**: Phase 0 대응표의 "Mode shape" (기초 개념만)

### 0-6 회전기계의 진동: 불평형과 1X (신규)
- **목표**
  - 불평형이 회전수와 같은 주파수(1X)로 도는 힘을 만들고, 그 힘이 회전수의 제곱으로 커진다는 것을 설명할 수 있다.
  - 1X가 고유진동수와 만나는 회전수(임계속도)에서 진폭이 커지고 위상이 바뀐다는 것을 0-4로 설명할 수 있다.
- **내용**
  - 여는 질문: 축이 돌면 왜 회전수와 같은 박자로 흔들릴까? 기동할 때 특정 회전수에서만 진동이 커졌다가 다시 줄어드는 이유는?
  - 회전수와 주파수: f = rpm/60 [Hz], Ω = 2πf [rad/s]. 3600 rpm = 60 Hz.
  - 불평형(Unbalance): 회전체의 무게 중심이 회전 중심에서 조금 벗어난 상태. 불평형 질량 m_u가 반지름 e에서 돌면 원심력 m_u e Ω²이 축과 함께 회전한다.
  - 회전하는 힘을 한 방향(예: 수평)에서 보면 F cos Ωt — 0-4의 주기 가진력과 같다 → 응답은 회전 주파수로 흔들린다. 이 성분을 1X(회전 주파수의 1배)라고 부른다.
  - 힘 ∝ Ω²: 회전수가 2배면 불평형 힘은 4배.
  - 임계속도(Critical speed): 1X가 계(로터 + 베어링 + 지지 구조)의 고유진동수와 만나는 회전수 → 공진.
  - 런업(Run-up: 회전수를 올리는 운전)에서 1X의 진폭과 위상을 기록하면, 임계속도에서 진폭이 피크가 되고 위상은 약 90° 늦어지며, 지나면 180° 쪽으로 간다 (0-4와 같은 원리). 임계속도보다 훨씬 빠르면 축이 무게 중심 둘레로 돌아 진폭이 일정한 값으로 수렴한다.
  - 그래서 운전 속도를 임계속도에서 떨어뜨려 설계한다 (분리여유, 4-1에서 자세히).
  - Part 1 연결: P1-0의 rpm·1X·차수, P1-3 smearing (런업처럼 측정 중 회전수가 변하면 스펙트럼 피크가 퍼진다).
- **수식**: `f = \mathrm{rpm}/60`, `\Omega = 2\pi f`, `F_u = m_u e\,\Omega^2`, 1자유도 불평형 응답 `\dfrac{X}{m_u e / M} = \dfrac{r^2}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}`, `r = \Omega/\omega_n` (M: 전체 질량, Contents §3)
- **랩**: LAB-UNB-01 불평형 런업 입문 — rpm 슬라이더(또는 런업 재생) → 도는 원판과 원심력 화살표, 수평 변위 파형, 진폭·위상 vs rpm 곡선 위의 현재 점 (LAB-AF-01의 입문판)
- **과제**: 3000 rpm의 1X는 몇 Hz? (50 Hz) 1800 → 3600 rpm이면 불평형 힘은? (4배) 임계속도에서 위상은? 임계속도보다 훨씬 빠르면 진폭은 어디로 가나? (m_u e / M)
- **함정**: 1X가 크면 무조건 불평형이라고 단정한다 (임계속도 근처의 공진, 축 휨, 정렬 불량도 1X를 키운다 → 0-8, 6-1). 회전수를 올리면 진동이 계속 커진다고 생각한다 (임계속도를 지나면 줄어든다).
- **원본**: Phase 0 대응표의 "Natural frequency ↔ Critical speed", "Forced response ↔ Unbalance response" (입문만. Bode/Polar·AF는 4-1)

### 0-7 기계 요소가 만드는 주파수: 한 바퀴에 몇 번? (신규, D-032)
- **목표**
  - 기계 요소(축·커플링·날개·기어·구름베어링·미끄럼 베어링·벨트·전동기/발전기·구조)가 각각 몇 Hz로 기계를 흔드는지 "한 바퀴에 몇 번 일어나나 × 회전수"로 계산할 수 있다.
  - 회전수를 따라 움직이는 주파수(회전 관련)와 움직이지 않는 주파수(전원·구조 고유진동수)를 구분할 수 있다.
  - 기계 구성을 보고 관심 주파수 구간을 정하고, 그 구간이 측정 설정(F_max·분해능)과 센서 선택으로 이어진다는 것을 말할 수 있다.
- **내용**
  - 여는 질문: 불평형은 한 바퀴에 한 번 미는 힘이라 1X였다 (0-6). 기어 이빨, 베어링 볼, 펌프 날개처럼 한 바퀴에 여러 번 일어나는 일은 몇 Hz로 기계를 흔들까?
  - 세는 규칙: 한 바퀴에 k번 일어나는 사건 → k × f_r (k × 1X). k가 정수면 1X의 정수배(하모닉) 자리에, 정수가 아니면 그 사이에 선다.
  - 축·로터: 불평형 1X (0-6). 정렬 불량·풀림은 한 바퀴에 여러 번 밀고 당겨 2X·3X를 만든다 (감별은 Part 6).
  - 커플링: 두 축을 잇는 곳. 정렬이 어긋나면 2X와 축방향 성분이 커진다 (6-2).
  - 날개(펌프 베인·팬·압축기·터빈 블레이드): 날개 N_b개가 한 점을 지나는 횟수 → 날개 통과 주파수 N_b × f_r.
  - 기어: 이빨 z개가 맞물리는 횟수 → 맞물림 주파수 GMF = z × f_r. 맞물린 두 기어의 GMF는 같다 (z₁f₁ = z₂f₂ → 회전수비는 잇수비의 역수). 맞물림의 크기가 축 회전으로 출렁이면 GMF 옆에 측대역이 선다는 것은 1-7에서.
  - 구름베어링: 볼 N_r개를 잡은 케이지는 축보다 느리게(약 0.4배) 돈다 → FTF ≈ 0.4 f_r. 고정된 바깥 바퀴의 한 점을 볼이 지나는 횟수 BPFO = N_r × FTF ≈ 0.4 N_r f_r, 축과 함께 도는 안쪽 바퀴의 한 점은 BPFI = N_r × (f_r − FTF) ≈ 0.6 N_r f_r, 볼의 자전 BSF. **정수배가 아니라 하모닉 사이에 선다** — 구름베어링을 알아보는 단서. 정확한 식(볼 지름·피치 지름·접촉각)은 6-4.
  - 구름베어링·기어의 충격: 흠이 생기면 짧은 충격이 되풀이되고, 충격은 하우징·부품의 고유진동수(수 kHz)를 울린다 (0-3 감쇠 자유진동, 0-4 공진) → 결함 주파수보다 훨씬 높은 구간도 봐야 한다.
  - 미끄럼(유막) 베어링: 축과 베어링 사이의 기름이 축 속도의 절반 남짓으로 돈다 → 기름막이 불안정하면 0.38 ~ 0.48X (4-3, 6-3). GT/ST의 주 로터는 이 베어링 위에서 돈다.
  - 벨트: 벨트가 한 바퀴 도는 동안 풀리는 여러 바퀴 돈다 → f_belt = π D f_r / L, 1X보다 낮다.
  - 전동기·발전기: 자기력은 전원 한 주기에 두 번 커진다 → 2 f_L (전원 60 Hz → 120 Hz). 회전수가 아니라 전원에 묶여 있다. 3600 rpm 2극 발전기에서는 2X도 120 Hz라 주파수로는 겹친다 (6-6).
  - 구조(기초·케이싱·배관): 고유진동수 (0-2). 회전수와 무관하게 제자리에 있고, 가진 주파수가 그 근처를 지나면 커진다 (0-4).
  - 회전수를 바꾸면: 회전 관련 줄은 같은 비율로 움직이고 전원·구조 줄은 그대로다 → 0-8 증거 5요소의 "운전조건 의존성".
  - 관심 주파수 구간 지도 (예: 3600 rpm, 1X = 60 Hz): 1X 아래 — 유막 휠, 케이지, 벨트 / 1X ~ 10X — 불평형·정렬·풀림의 하모닉, 2 f_L, 구름베어링 결함 주파수 / 10X ~ 수 kHz — 날개 통과, 기어 맞물림과 그 2·3배 / 수 kHz 이상 — 충격이 울리는 구조 공진 대역.
  - 기계마다 지도가 다르다: 미끄럼 베어링 위의 GT/ST 주 로터는 1X 아래 ~ 수 X가 중심(축 변위, Part 2). 구름베어링·기어는 윤활유 펌프·팬·GT 보조 기어박스 같은 보조기기에서 kHz까지 간다.
  - Part 1 연결: 관심 구간의 위 끝 → F_max (1-2, 1-8), 가까운 줄 사이 간격 → 분해능 (1-3), GMF 측대역 → 1-7. 센서 선택은 2-1.
- **수식**: `f_r = \mathrm{rpm}/60`, `f = k\,f_r`, `f_{GM} = z\,f_r`, `f_{BP} = N_b\,f_r`, `f_{FTF} \approx 0.4\,f_r`, `f_{BPFO} = N_r f_{FTF}`, `f_{BPFI} = N_r (f_r - f_{FTF})`, `f_{belt} = \pi D f_r / L`, `2 f_L` (기호 Contents §3)
- **랩**: LAB-FMAP-01 주파수 지도 — 기계 고르기(전동기-펌프 / 기어 상자 / GT-발전기 축계 / 벨트 구동 팬) + rpm + 잇수·볼 수·날개 수 → 주파수 축 위의 요소별 줄과 관심 구간 띠. rpm을 바꾸면 따라 움직이는 줄과 고정된 줄이 갈린다 (Contents §5)
- **과제**: 3600 rpm 펌프, 날개 7개 → 날개 통과는? (420 Hz) 이빨 15·60 기어, 입력 3000 rpm → 맞물림과 출력 축 회전수는? (750 Hz, 12.5 Hz) 볼 9개 베어링, 3000 rpm → BPFO·BPFI는 대략? (≈ 180 Hz, 270 Hz) 회전수를 10 % 올려도 제자리인 줄은? (2 f_L, 구조 고유진동수)
- **함정**: 모든 봉우리를 1X의 정수배로 보려 한다 (구름베어링은 정수배가 아니다). 2 f_L과 2X를 같은 것으로 본다 (2극 발전기에서만 겹친다). 맞물림·날개 통과 주파수가 보이면 결함이라고 단정한다 (정상 기계에도 있다. 크기·측대역의 변화를 본다 → Part 6).
- **원본**: 4-1 결함 지도와 4-2 베어링 식 중 "요소 → 주파수" 부분을 입문 수준으로 앞당김 (D-032). 결함 패턴·정확한 식은 6-0, 6-4, 6-5

### 0-8 응답에서 원인으로: 진단은 거꾸로 푸는 문제 (신규, 옛 0-1 재구성)
- **목표**
  - 센서 신호가 여러 원인의 응답이 더해진 것이라는 것을 설명할 수 있다.
  - 진단이 "응답에서 원인을 추정하는" 거꾸로 푸는 문제이고 답이 하나로 정해지지 않을 수 있다는 것, 그래서 증거 5요소를 교차 확인한다는 것을 설명할 수 있다.
  - 합쳐진 신호를 다시 성분으로 나눠야 하는 이유(Part 1의 동기)를 말할 수 있다.
- **내용**
  - 여는 질문: 센서에 찍힌 파형 한 줄에서 원인을 어떻게 찾을까?
  - 한 기계 안의 여러 원인 (주파수는 0-7의 지도): 1X(불평형, 0-6), 2X(한 바퀴에 두 번 — 축 정렬 불량 등에서 흔함), 날개 통과(날개 수 × 1X: 날개가 지나갈 때마다 생기는 압력 맥동), 구조 공진(고유진동수 근처 성분이 증폭됨, 0-4), 잡음.
  - 선형계에서는 응답이 더해진다(0-5 중첩) → 센서에는 그 합 하나만 찍힌다.
  - 앞에서는 원인(m, c, k, 힘)을 알고 응답을 예측했다(순문제). 진단은 그 반대다 — 응답에서 원인을 추정한다(역문제). 같은 1X 피크도 큰 불평형일 수도, 작은 불평형 + 공진일 수도 있어서 답이 하나로 정해지지 않을 수 있다.
  - 그래서 한 가지 증거로 단정하지 않고 증거 5요소를 교차 확인한다: 주파수(몇 X) · 진폭 · 위상 · 방향(수평/수직/축방향) · 운전조건 의존성(속도·부하·온도·시간).
  - Part 0 개념이 뒤에서 어떤 측정·플롯으로 나타나나 (지도)

    | Part 0 개념 | 측정·플롯에서는 | 어디서 |
    |---|---|---|
    | 고유진동수 (0-2) | 임계속도(로터), 구조 공진(케이싱·기초·배관) | 4-1, 8-1 |
    | 모드 형상 (0-5) | 베어링 간 위상 비교, Polar 루프, ODS | 5-5, 8-1 |
    | 감쇠비 ζ (0-3) | 증폭계수 AF, Half-power, Log decrement | 4-1, 4-3 |
    | FRF (0-4) | 임팩트/범프 테스트, 런업 데이터 | 3-4, 8-1 |
    | 강제 응답·불평형 (0-4, 0-6) | 불평형 응답, 1X 벡터 | 2-3, 4-1 |
    | 감쇠 자유진동: 줄어드나, 커지나 (0-3) | 안정성, Log decrement, 서브싱크로너스 진동 | 4-3 |
    | 중첩 (0-5) | 스펙트럼 성분 분리. 비선형(축이 닿는 러브, 체결이 헐거운 풀림)이면 하모닉·분수 하모닉이 생김 | 6-2 |
    | 대칭인 질량·강성 행렬 (0-5) | 회전체는 교차연성·자이로 효과로 비대칭 → 정/역 프리세션 | 4-2, 4-3 |

  - Part 1 연결: 한 줄로 합쳐진 파형을 다시 성분으로 나누는 도구가 스펙트럼이다 → Part 1 전체의 동기 (P1-0).
- **수식**: `x(t) = \sum_i A_i\cos(2\pi f_i t + \phi_i)` + 잡음, 원인 주파수 예: 1X = rpm/60, 2X, 날개 통과 = N_b × 1X (N_b: 날개 수)
- **랩**: LAB-SRC-01 원인 합성 — 원인 3개(예: 1X 불평형, 2X, 날개 통과)를 켜고 크기를 바꾸면 원인별 응답과 합친 파형 한 줄이 보인다. 원인을 가린 합 파형에서 원인 맞히기 → "다시 나누려면?" (스펙트럼 미리 보기, P1-0에서 자세히)
- **과제**: 합친 파형만 보고 원인이 몇 개인지 말할 수 있나? 1X 진폭을 키우는 원인을 불평형 말고 두 가지 들어 보자. 위 지도의 "어디서" 칸을 가리고 채워 보기 (자가 점검).
- **함정**: "1X가 크다 = 불평형"처럼 한 가지 증거로 단정한다. 파형 모양만 보고 원인을 고른다.
- **원본**: Phase 0 "사고방식 전환"과 대응표 (재구성: 대응표를 "Part 0 개념 → 측정·플롯" 지도로 바꿈)

## Part 1. 신호처리 기초 ★

### 1-0 신호와 스펙트럼의 기본 (신규, D-024)
- **목표**: Part 1 전체가 쓰는 기본 용어를 처음부터 정리한다. Part 0(진동의 기초)을 읽었으면 따라올 수 있어야 한다.
- **내용**

  - 진동 신호와 시간파형, 측정량 3종(변위·속도·가속도)과 단위
  - P0-2 되짚기: 정현파의 진폭·주기·주파수·각주파수·위상 (위상차와 조작 랩은 P0-2로 안내)
  - P0-6 되짚기: 회전수와 주파수(f_r = rpm/60), 1X·nX. 차수와 서브싱크로너스는 주파수 위치의 이름으로 소개하며 원인 확정과 구분
  - Peak·Pk-Pk·RMS·평균(DC), 평균 0 정현파 환산과 그 한계, Crest factor. RMS 단위와 DC 포함 여부, 랩 네 모양과 배율의 수치 해석
  - 스펙트럼이란 무엇인가 (FRF와의 차이)
  - 샘플링의 기본: 샘플, Δt, f_s, N, T = N/f_s, 기본 눈금 간격 Δf = 1/T, 나이퀴스트 경계·에일리어싱 소개. 눈금 간격과 실제 분해능의 차이는 P1-3으로 안내
- **랩**: LAB-BAS-01 정현파의 세 숫자는 M2.2에서 0-2로 이동 완료(P1-0에는 위치 안내, D-027). P1-0에는 LAB-BAS-02 진폭 표기 비교(사용자 요청으로 추가, D-026). 개념마다 예시 그림

### 1-1 푸리에 기초: 신호를 주파수로 보는 법 (신규)
- **목표**
  - 주기 신호가 정현파의 합이라는 것과 스펙트럼의 의미를 설명할 수 있다.
  - DFT를 "각 주파수 정현파와의 상관(내적)"으로 이해한다.
  - 진폭·위상 스펙트럼, 복소 표현, 음의 주파수, 단일측/양측 스펙트럼을 구분한다.
- **내용**
  - 푸리에 급수: 사각파·톱니파·펄스열의 하모닉 구성. 펄스가 짧을수록 스펙트럼이 넓다.
  - 시간 ↔ 주파수 쌍대성: 짧은 것 ↔ 넓은 것 → 임팩트는 광대역 가진 (8-1 임팩트 시험의 원리).
  - DFT = 정현파 템플릿과의 상관. bin k는 "프레임 안에 정확히 k주기 들어가는" 템플릿이다.
  - 복소 지수와 회전 벡터(phasor): cos = (e^{jωt} + e^{−jωt})/2 → 양측 스펙트럼에 ±f. 실신호는 대칭이라 단일측으로 접고 2배.
  - 위상 스펙트럼: 진폭이 작은 bin의 위상은 잡음이라 의미 없다.
  - **제로패딩은 분해능을 올리지 않는다**: bin 간격만 촘촘해지는 보간이고, 두 성분을 분리하는 능력(≈ 1/T)은 그대로다.
  - FFT는 DFT의 빠른 알고리즘 (N log N). N을 2의 거듭제곱으로 쓰는 이유.
- **수식**: 푸리에 급수, DFT, 오일러 공식, Parseval
- **랩**: LAB-FOU-01 — (a) 하모닉 쌓기: 진폭·위상 슬라이더로 사각파 만들기 (b) DFT 상관 시각화: 신호 × 템플릿의 면적 = 실수부/허수부 (c) 제로패딩 on/off
- **과제**: 하모닉 위상만 바꾸면 파형과 Crest factor는 바뀌지만 진폭 스펙트럼은 그대로임을 확인한다 (→ 시간파형도 봐야 하는 이유, 5-1). 사각파에는 왜 홀수 하모닉만 있나?
- **함정**: 제로패딩으로 분해능 문제를 풀려고 한다. 잡음 bin의 위상을 해석한다.
- **원본**: 없음 (Phase 1의 전제 지식)

### 1-2 샘플링 · 에일리어싱 · AAF · ADC
- **목표**
  - 에일리어싱이 생기는 조건과 겉보기 주파수를 계산할 수 있다.
  - f_s = 2.56 F_max의 이유를 AAF 전이대역으로 설명할 수 있다.
  - ADC 비트 수와 입력 레인지가 동적범위·클리핑에 미치는 영향을 안다.
- **내용**
  - 샘플링은 신호를 t = n/f_s에서만 본다. f_s/2를 넘는 성분은 접혀 들어와 진짜와 구분할 수 없다.
  - 에일리어싱은 샘플링 **후에는 제거할 수 없다** → 아날로그 AAF가 ADC 앞에 있어야 한다.
  - 2.56의 이유: F_max ~ 1.56 F_max의 전이대역 확보 + 2.56 × LOR이 2의 거듭제곱 (400 line → 1024). N/2 = 1.28 LOR bin 중 LOR개만 표시한다.
  - 현대 분석기: 높은 f_s로 받고 디지털 LPF + 다운샘플(데시메이션) → 3-1.
  - ADC: 이상적 SNR ≈ 6.02·b + 1.76 dB (16 bit ≈ 98 dB, 24 bit ≈ 146 dB, 실제 유효 비트는 더 낮음).
  - 입력 레인지: 너무 크면 양자화 잡음에 작은 성분이 묻히고, 너무 작으면 클리핑 → 시간파형 꼭대기가 평평해지고 스펙트럼에 가짜 하모닉이 생긴다.
  - F_max 선정 관례 (출처마다 다름, I-014): 일반 점검은 1X의 10~20배 이상, 구름베어링은 결함 주파수 하모닉까지(원본 40~50X), 기어는 GMF의 3배 이상(원본 3.5×GMF, 측대역 포함), 로터 거동(프록시미티)은 10X 내외.
- **수식**: 나이퀴스트, 에일리어스 주파수, `f_s = 2.56 F_max`, `SNR_{ADC} \approx 6.02\,b + 1.76` dB
- **랩**: LAB-SMP-01 샘플링 & 에일리어싱, LAB-SMP-02 AAF와 2.56, LAB-SMP-03 ADC & 입력 레인지
- **과제**: f_s 1000 Hz에서 940 Hz가 어디에 보이나? AAF 없이 1.8 F_max 성분은? 입력 레인지를 신호보다 작게 하면 스펙트럼에 무엇이 생기나?
- **함정**: 화면의 F_max만 보고 AAF가 있다고 가정한다 (AAF 없는 범용 DAQ도 많다). 클리핑된 데이터를 그대로 해석한다.
- **원본**: 1-1 (+ ADC, 데시메이션 보강)

### 1-3 분해능 · 측정 시간 · Zoom FFT
- **목표**
  - Δf·T·N의 관계로 측정 설정을 정하고, 두 성분이 분리되는지 판단할 수 있다.
  - Smearing과 Zoom FFT의 원리를 안다.
- **내용**
  - 분해능 3식과 "측정 시간 T를 먼저 생각하는 습관" (Δf 0.1 Hz → T 10 s).
  - 분리 기준은 윈도우 메인로브 폭에 달렸다: Uniform ±1 bin, Hann ±2 bin, Flat top 약 ±5 bin → 필요한 bin 수가 다르다.
  - 원본 사례: 60 Hz vs 120 Hz (쉬움), 2극 발전기 1X vs LF (주파수가 같아 FFT로 분리 불가), Oil whirl 0.42X vs 0.48X, 저속 축 BPFI ± 1X 측대역.
  - 2극 동기 발전기의 1X = LF는 다른 증거로 구분한다: 전원 차단(트립) 시 즉시 사라지면 전기적, 회전수를 따라 서서히 줄면 기계적. 유도전동기라면 슬립만큼 차이가 나서 고분해능 + 맥놀이(1-7)로 볼 수 있다.
  - Smearing: 측정 중 회전수가 변하면 피크가 퍼진다 → 차수추적(3-5)이 필요하다.
  - Zoom FFT: 관심 대역을 복소 복조(주파수 이동) + LPF + 데시메이션으로 확대 → 같은 N으로 좁은 대역에서 고분해능. 단, 측정 시간은 여전히 1/Δf다 (공짜가 아님).
- **수식**: 분해능 3식, `분리 bin = |f₁ − f₂|/Δf`, `퍼진 bin = (a/60)\,T^2`
- **랩**: LAB-RES-01 두 성분 분리, LAB-RES-02 Smearing, LAB-ZOOM-01 Zoom FFT
- **과제**: 원본 과제 — F_max 1000 Hz, 3200 line → Δf, T? 코스트다운 60 rpm/s면 프레임 동안 1X가 얼마나 변하나?
- **함정**: 제로패딩으로 분해능을 올렸다고 착각한다. 운전 조건이 변하는 중에 고분해능 측정을 한다.
- **원본**: 1-2 (+ Zoom FFT, 메인로브 기준 보강)

### 1-4 윈도우
- **목표**
  - 누설과 피켓펜스를 설명하고, 목적에 맞는 윈도우를 고를 수 있다.
  - 진폭 보정(ACF), 에너지 보정(ECF/ENBW), 스캘럽 손실을 구분한다.
- **내용**
  - 누설의 원인: 프레임 경계의 불연속 (프레임에 비정수 주기가 들어감). "주기 연장" 그림으로 본다.
  - 윈도우 = 시간영역 곱 = 주파수영역 컨볼루션 → 윈도우 스펙트럼 모양이 모든 톤에 찍힌다.
  - 메인로브 폭 vs 사이드로브 레벨·감쇠율의 트레이드오프 (특성표: Contents §6).
  - 선택 가이드
    - Uniform: 프레임 안에서 끝나는 과도신호, 동기 샘플링으로 정수 주기가 보장될 때(차수추적·TSA)
    - Hann(흔히 Hanning): 일반 상시 진동의 기본값
    - Flat top: 진폭 정확도 (교정, 밸런싱 전 1X 진폭, 레벨 판정)
    - Blackman-Harris / Kaiser: 큰 성분 옆 작은 성분 (동적범위)
    - Force / Exponential: 임팩트 시험 (8-1). Exponential은 인위 감쇠를 더하므로 ζ를 보정해야 한다.
  - 보정 3종 구분 (I-007): CG/ACF는 톤 진폭 기준, ECF/ENBW는 잡음 파워 기준, 스캘럽 손실은 bin 오프셋 오차라 보정계수로 고쳐지지 않는다 (Flat top이나 피크 보간으로 해결).
  - 피크 보간(심화): 인접 bin 비율로 정확한 주파수·진폭을 추정한다 (밸런싱 장비 등에서 사용).
- **수식**: CG, ACF, ECF, ENBW, 스캘럽 손실, 지수 윈도우 감쇠 보정 `\zeta_{true} \approx \zeta_{meas} - \dfrac{1}{\tau\,\omega_n}` (w(t) = e^{−t/τ})
- **랩**: LAB-WIN-01 누설 & 피켓펜스, LAB-WIN-02 동적범위, LAB-WIN-03 보정계수 & ENBW
- **과제**: 원본 실습 4 — 톤을 bin 중심/bin 사이에 놓고 Uniform·Hann·Flat top 진폭 비교표를 채운다.
- **함정**: Flat top으로 가까운 두 성분을 분리하려 한다. 지수 윈도우를 쓰고 ζ를 그대로 보고한다.
- **원본**: 1-3

### 1-5 평균화와 TSA
- **목표**: 평균 방식마다 무엇이 개선되는지 구분하고, 평균 횟수·오버랩·총 측정 시간을 설계할 수 있다.
- **내용**
  - RMS(파워) 평균: 잡음 바닥의 평균 레벨은 그대로, 흔들림만 1/√M로 감소 (I-005).
  - 벡터(트리거 동기) 평균: 트리거와 비동기인 성분·잡음의 진폭 자체가 1/√M로 감소 → SNR 개선. 트리거 = 키페이저.
  - 지수 평균: 변하는 상태 추적, 최근 값 가중.
  - 피크홀드: 런업/코스트다운 최대값, 범프 테스트. 잡음 스파이크도 붙잡는다는 점에 주의.
  - 오버랩: Hann 끝단 가중 손실 보상, 같은 시간에 더 많은 평균. Uniform에서는 겹친 구간끼리 상관이 커서 이득이 작다 (원본 "무의미"를 완화, I-011).
  - TSA: 회전 각도 기준 평균 = 빗살(comb) 필터. 비동기 성분 제거 → 특정 축 분리. Regular / Residual / Difference 신호 개념(기어 진단).
  - 평균 횟수 경험칙: 흔들림(dB) ≈ 4.34/√M → ±1 dB면 M ≈ 19, ±0.5 dB면 M ≈ 75.
- **수식**: 각 평균 식, 오버랩 총 측정시간, TSA, TSA 비동기 성분 이득 (Contents §3)
- **랩**: LAB-AVG-01 평균화, LAB-AVG-02 TSA
- **과제**: Hann + 75 % 오버랩 + M = 16의 총 측정시간은? RMS 평균 vs 벡터 평균에서 작은 동기 톤이 드러나는 쪽은?
- **함정**: 운전 상태가 변하는데 긴 선형 평균을 건다. 피크홀드 값을 정상 운전 레벨로 보고한다.
- **원본**: 1-4

### 1-6 스펙트럼 스케일링과 진동 단위
- **목표**: Linear/Power/PSD를 신호 종류에 맞게 고르고, Pk·Pk-Pk·RMS와 변위·속도·가속도 단위를 자유롭게 환산할 수 있다.
- **내용**
  - 톤은 Δf에 무관한 진폭/파워 스펙트럼으로, 랜덤은 Δf에 무관한 PSD로 본다. 대역 RMS = √(∫PSD df) — 그래서 랜덤에는 PSD를 쓴다.
  - 스펙트럼에서 overall 계산: 대역 bin 파워 합을 ENBW로 나눠야 한다 (윈도우 보정, 1-4 연결).
  - Pk / Pk-Pk / RMS: 정현파 관계는 정현파일 때만 성립. 많은 장비가 "derived peak(√2·RMS)"를 표시하므로 true peak와 다를 수 있다.
  - 업계 관례: 프록시미티 변위는 µm pp(mils pp), 케이싱 속도는 mm/s rms(ISO) 또는 in/s pk(미국), 가속도는 g pk 또는 g rms. 1 mil = 25.4 µm, 1 in/s pk = 17.96 mm/s rms.
  - 정현파 환산: v = 2πf·d, a = (2πf)²·d → 같은 진동도 주파수에 따라 어느 양이 큰지가 다르다 (→ 3-2: 저주파는 변위, 고주파는 가속도).
  - dB: 진폭은 20 log, 파워는 10 log. 기준값 관례 (I-006). 하모닉 패밀리·작은 성분은 dB/로그 축에서 보인다.
- **수식**: PS, PSD, 대역 RMS, `v = 2\pi f d`, `a = (2\pi f)^2 d`, dB
- **랩**: LAB-SPC-01 Linear/Power/PSD, LAB-SPC-02 진폭 표기·dB, LAB-UNIT-01 단위 환산기
- **과제**: 25 Hz, 50 µm pp 변위는 몇 mm/s rms인가? (≈ 2.78 mm/s rms) LOR을 8배로 늘리면 톤의 PSD와 잡음의 Power는 각각 어떻게 되나?
- **함정**: derived peak와 true peak를 섞어 비교한다. in/s pk와 mm/s rms를 그대로 비교한다.
- **원본**: 1-5 (+ 단위 관례, 대역 RMS 보강)

### 1-7 변조 · 측대역 · 맥놀이 (신규)
- **목표**: 측대역이 왜 생기는지(AM/FM)와 측대역 간격이 무엇을 가리키는지 설명하고, 맥놀이를 알아볼 수 있다.
- **내용**
  - AM: (1 + m cos 2πf_m t)·cos 2πf_c t → f_c ± f_m, 측대역 진폭 = 반송파 × m/2.
  - FM/PM: 베셀 함수 계열의 많은 측대역. AM과 FM이 함께 있으면 측대역이 비대칭이 된다.
  - 현장 예: 기어 편심 → 회전 주기 AM / 피치 오차 → FM / 베어링 내륜 결함 → 하중영역 통과로 1X AM / 유도전동기 로터바 → 극통과 주파수 측대역.
  - **측대역 간격 = 변조 원인의 주파수** → "어느 축이 원인인가"를 알려준다.
  - 맥놀이(Beat): 가까운 두 주파수의 합 → 포락선이 |f₁ − f₂|로 맥동. 현장: 인접한 두 기계의 회전수 차이, 유도전동기 2X vs 2×LF 등. 시간파형 진폭이 주기적으로 오르내린다.
  - 맥놀이 vs AM 구별: 스펙트럼에 두 피크만 있나(맥놀이), 반송파 + 대칭 측대역인가(AM).
  - 두 피크를 분리하려면 T > 1/|f₁ − f₂| (실무상 2~3배) → 1-3과 연결.
- **수식**: AM, FM `x = \cos(2\pi f_c t + \beta \sin 2\pi f_m t) = \sum_n J_n(\beta)\cos 2\pi (f_c + n f_m) t`, 맥놀이 `\cos a + \cos b = 2\cos\frac{a-b}{2}\cos\frac{a+b}{2}`
- **랩**: LAB-MOD-01 — AM/FM/맥놀이 모드, f_c, f_m, m, β → 시간파형 + 포락선, dB 스펙트럼, 측대역 간격 자동 표시
- **과제**: 맥놀이 주기가 4초면 두 주파수 차이는? (0.25 Hz) 분리하려면 T는 최소 얼마?
- **함정**: 맥놀이를 결함에 의한 진폭 변동으로 오인한다. 분해능이 부족해 측대역이 반송파에 묻힌다.
- **원본**: 없음 (Phase 4의 측대역 해석에 필요한 전제)

### 1-8 측정 설정 종합: 목적별 의사결정 (신규)
- **목표**: 측정 목적이 주어지면 F_max, LOR, 윈도우, 평균, 오버랩, 단위를 스스로 정하고 근거를 말할 수 있다.
- **내용**
  - 결정 순서: 목적(무엇을 보려나) → 관심 최고 주파수 → F_max → 분리해야 할 최소 간격 → LOR → T가 운전 안정 시간 안인가 → 윈도우(톤 진폭 / 분리 / 동적범위 / 과도) → 평균(방식·횟수·오버랩) → 총 측정 시간 → 단위·표기

    | 목적 | F_max | LOR | 윈도우 | 평균 | 비고 |

    | 1X 진폭·위상 (밸런싱) | 10X | 400 | Flat top 또는 동기 샘플 + Uniform | 벡터 | 키페이저 필요 |

    | 기어 | 3×GMF 이상 | 3200 이상 | Hann | RMS / TSA | 측대역 간격 = 축 회전수 |

- **과제**: 세 가지 시나리오(오일 휠 의심, 베어링 점검, 밸런싱 전 측정)의 설정을 정하고 샌드박스 합성 신호로 검증한다.
- **함정**: 기본 설정(400 line, Hann)으로 모든 측정을 한다.

## Part 2. 센서와 측정 체인

### 2-1 센서 원리와 선택
- **목표**: 세 센서의 원리·대역·장단점을 설명하고, 왜 GT/ST는 프록시미티 프로브가 주인지 말할 수 있다.
- **내용**
  - 프록시미티(와전류): 축과 베어링 하우징 사이의 상대 변위, DC 성분(gap) 포함, 표적 재질에 의존(보통 4140강 기준 교정). 실무상 고주파에서는 변위 진폭이 작아 의미가 줄어든다.
  - 속도계: 동전형(지진계형)은 자체 고유진동수(수~10 Hz) 위에서 평탄, 저주파에서 위상 오차, 기계적 마모. 압전 속도계(내장 적분형 가속도계)도 있다.
  - 가속도계(압전, IEPE/ICP): 공진 주파수보다 충분히 낮은 대역에서 평탄, 센서 질량 효과, 감도(예: 100 mV/g).
  - **센서 자체가 MCK 계다** (0-4 강제진동·공진의 응용): 가속도계는 r ≪ 1 영역, 동전형 속도계는 r ≫ 1 영역을 쓴다. 대역 한계와 마운팅 영향이 1자유도 기초가진 응답으로 설명된다.
  - 왜 GT/ST는 프록시미티: 무거운 케이싱과 유막 베어링 때문에 로터 진동이 케이싱으로 잘 전달되지 않는다. 축 절대 진동 = 프록시미티(상대) + 케이싱 센서(절대) 합성 (dual probe).
- **수식**: 1자유도 기초가진 응답 (센서 모델)
- **랩**: LAB-SNS-01 — 센서 고유진동수, 감쇠, 마운팅(스터드 → 접착 → 자석 → 핸드) → 진폭·위상 응답과 측정 스펙트럼의 왜곡
- **과제**: 공진 25 kHz 가속도계의 ±10 % 평탄 대역 상한은? (감쇠 무시 시 약 7.5 kHz)
- **함정**: 자석 마운트로 고주파를 잰다. 동전형 속도계로 저속 기계를 잰다.
- **원본**: 2-1

### 2-2 프록시미티 프로브 시스템
- **목표**: gap 전압을 거리로 바꾸고, 선형 범위·감도·런아웃의 의미를 이해한다.
- **내용**
  - 구성: 프로브 + 연장 케이블 + 프록시미터(드라이버). 전체 길이가 맞춰진 상태로 교정된다.
  - 감도 예: 7.87 V/mm (200 mV/mil). 출력은 음전압, gap이 커질수록 더 음.
  - Gap 전압(DC) = 평균 거리 → Shaft centerline 계산 (5-4). 선형 범위를 벗어나면 파형이 왜곡된다.
  - AC 성분 = 축 상대 진동 (µm pp).
  - 런아웃: 기계적(진원도, 흠집, 휨) + 전기적(재질 불균질, 잔류 자기, 도금) → 저속에서도 보이는 "가짜 진동".
  - 설치: X-Y는 수직선 기준 ±45° 배치가 관례, 프로브 간 간섭 거리, 브래킷 공진, 축 표면 처리.
- **수식**: `d = V_{gap} / S` (S: 감도)
- **랩**: LAB-PROX-01 — 감도·gap → 출력 전압과 선형 범위, 축 진동 + 런아웃 합성 신호
- **과제**: gap −9.5 V, 감도 7.87 V/mm면 거리는? (≈ 1.21 mm)
- **함정**: 표적 재질이나 케이블 길이가 다른데 교정값을 그대로 쓴다. 런아웃을 보상하지 않는다.
- **원본**: 2-1 (Gap voltage, 런아웃)

### 2-3 키페이저 · 위상 · 1X 벡터
- **목표**: 위상의 정의(관례)를 알고, 1X 벡터 연산과 Slow roll 보상을 할 수 있으며, 위상으로 진단할 수 있다.
- **내용**
  - 키페이저: 축의 홈이나 돌기 → 1회전 1펄스 → 회전수 + 위상 기준. 없으면 밸런싱·오빗 dot·Bode 위상이 모두 불가.
  - 위상 정의: Bently 관례는 키페이저 펄스에서 1X 필터 신호의 다음 양(+) 피크까지의 지연각(phase lag, 0~360°). 장비마다 관례가 달라(lag/lead, 피크/영점) 데이터 비교 전 반드시 확인한다.
  - 위상 측정 방법: 시간 차이 → 각도, 트래킹 필터(3-6), 동기 샘플링 후 DFT 위상.
  - 1X 벡터 = 진폭∠위상 = Polar 플롯의 한 점.
  - Slow roll 보상: 동적 효과가 무시되는 저속 구간(원본 150~600 rpm)의 1X 벡터 = 런아웃 → 모든 회전수의 벡터에서 **복소수로** 뺀다. 시간파형 보상도 있다.
  - 위상으로 진단: 같은 평면 X-Y 위상차 약 90°(원형 오빗) vs 0°/180°(선형 진동, 구조적 구속) / 베어링 간 동상(병진 모드, 정적 불평형) vs 역상(원추 모드, 커플 불평형) / 커플링 양쪽 축방향 위상 약 180°(미스얼라인).
- **수식**: `\vec V = A\,e^{-j\phi}`, `\vec V_c = \vec V - \vec V_{sr}`
- **랩**: LAB-PHS-01 위상 측정 (키페이저 펄스 + 1X 파형, 관례에 따른 위상값 변화), LAB-SRO-01 Slow roll 보상 (Bode/Polar 전후 비교)
- **과제**: 1X 벡터 50 µm∠120°에서 slow roll 15 µm∠60°를 빼면? (≈ 44.4 µm∠137°)
- **함정**: 관례가 다른 장비의 위상을 그대로 비교한다. 런아웃을 스칼라로 뺀다. Slow roll 구간을 너무 높은 회전수에서 잡는다.
- **원본**: 2-1 (Keyphasor, Slow roll), 4-1 위상 구별 포인트

### 2-4 측정 체인 함정
- **목표**: 측정값이 진짜인지 의심하고 확인하는 습관을 들인다.
- **내용**
  - 마운팅별 사용 가능 대역: 스터드 > 접착 > 자석 > 핸드 (원본: 핸드 ~1 kHz).
  - IEPE/ICP: 정전류 공급, 바이어스 전압 확인으로 센서·케이블 고장 진단, 정착 시간(settling), AC 결합에 의한 저주파 손실.
  - Ski-slope: 저주파 잡음이 적분으로 1/ω 증폭 (3-2). 원인: 열충격, 과부하, 저주파 잡음.
  - 그라운드 루프: 50/60 Hz와 하모닉 잡음 → 전기적 결함(6-6)과 혼동.
  - 케이블: 마찰전기(triboelectric) 잡음 → 케이블 고정.
  - 센서 공진 근처 증폭: 고주파 피크가 기계가 아니라 센서 공진일 수 있다.
  - 확인 습관: 센서 교체·재측정, 바이어스 확인, 시간파형 확인, 같은 위치 다른 센서 비교.
- **랩**: LAB-CHAIN-01 — 의심스러운 측정 판정 퀴즈 (사례 7개 × 확인 동작, M3.4). ski-slope·적분 모델은 P3-2의 LAB-INT-01이 이어 쓴다
- **함정**: 센서 문제를 기계 문제로 보고한다.
- **원본**: 2-2

## Part 3. 신호처리 확장

### 3-1 디지털 필터
- **목표**: 필터 종류와 차수에 따른 크기·위상 응답을 이해하고, 위상 왜곡과 zero-phase 필터링을 구분한다.
- **내용**
  - 사양: 통과대역, 차단대역, 전이대역, 리플, 감쇠량. 롤오프 = 차수 n당 6 dB/oct (20 dB/dec).
  - IIR: Butterworth(평탄), Chebyshev(가파름 + 리플), Bessel(선형 위상 근사), Elliptic(가장 가파름).
  - FIR: 선형 위상 가능, 대신 차수가 높다.
  - 위상 왜곡: 하모닉 간 위상 관계가 깨져 시간파형 모양이 바뀐다 → 파형 진단 왜곡. 군지연.
  - filtfilt(zero-phase): 정·역방향 두 번 → 위상 0, 크기 응답 제곱. 오프라인 전용.
  - 데시메이션: LPF + 다운샘플 (1-2, 1-3 Zoom과 연결).
- **수식**: Butterworth `|H| = 1/\sqrt{1 + (f/f_c)^{2n}}`, 군지연 `\tau_g = -d\phi/d\omega`
- **랩**: LAB-FLT-01 — 종류·차수·차단주파수 → 크기/위상/군지연, 사각파·임펄스 통과 결과, filtfilt 비교
- **함정**: 위상이 중요한 파형 분석에 고차 IIR을 그대로 쓴다.
- **원본**: 3-1

### 3-2 적분과 미분
- **목표**: 가속도·속도·변위를 오가며 변환하고, ski-slope에 대처한다.
- **내용**
  - 주파수영역 적분: V(f) = A(f)/(j2πf) → 진폭 1/ω, 위상 −90°. DC 근처 발산 → 하한 컷오프 필요.
  - 시간영역 적분: 누적합 + 드리프트 → HP 필터 필요. 이중 적분(가속도 → 변위)은 특히 위험.
  - 어떤 양으로 볼 것인가: 저주파(<10 Hz) 변위, 중간(10~1000 Hz) 속도, 고주파(>1 kHz) 가속도. 기계 진동은 속도 스펙트럼이 비교적 평탄해서 속도가 일반 진단의 기본(ISO 평가량).
- **수식**: `V = A/(j\omega)`, `D = -A/\omega^2`
- **랩**: LAB-INT-01 — 가속도 신호(+ 저주파 잡음) → 속도/변위, 방식(시간/주파수), HP 컷오프 → ski-slope
- **원본**: 2-2 (Ski-slope), 3-3

### 3-3 시간-주파수 분석: STFT · 스펙트로그램 · 워터폴 (신규)
- **목표**: 시간에 따라 변하는 스펙트럼을 보고, 프레임 길이 트레이드오프와 Waterfall/Cascade의 원리를 이해한다.
- **내용**
  - STFT: 짧은 프레임을 밀면서 FFT → 스펙트로그램 (시간 × 주파수 × 진폭).
  - 시간-주파수 트레이드오프: 짧은 프레임은 시간이 정확하고 주파수가 흐리다, 긴 프레임은 반대 (Δt·Δf ~ 1).
  - Waterfall(시간축) vs Cascade(rpm축): 원리는 같고 축만 다르다.
  - 차수선: rpm을 따라 기울어진 선 = 회전 관련, 수직선(고정 주파수) = 구조 공진·전기·Oil whip.
  - (참고) 웨이블릿: 주파수마다 다른 프레임 길이를 쓰는 방식 — 개념만.
- **랩**: LAB-STFT-01 — 런업 신호(1X, 2X, 고정 공진, 0.45X whirl) → 프레임 길이·오버랩 → 스펙트로그램/워터폴
- **원본**: 6-2 (Spectrogram), Phase 5 Waterfall의 원리

### 3-4 2채널 분석: 교차 스펙트럼 · FRF · 코히어런스 · Full spectrum (신규)
- **목표**: 두 신호 사이의 전달·위상 관계를 정량화하고, Full spectrum의 수학을 이해한다.
- **내용**
  - 교차 스펙트럼 G_xy: 두 신호의 공통 성분 크기와 위상차.
  - FRF 추정: H1 = G_xy/G_xx (출력 잡음에 강함), H2 = G_yy/G_yx (입력 잡음에 강함).
  - 코히어런스 γ² = |G_xy|²/(G_xx·G_yy), 0~1. **평균이 필수** — M = 1이면 항상 1이다. 임팩트 시험 품질 판단(8-1).
  - 채널 간 위상: 베어링 간 위상, 커플링 양쪽 축방향 위상(6-2), ODS(8-1).
  - Full spectrum: z = x + jy의 복소 FFT → 양의 주파수 = 정방향(forward), 음의 주파수 = 역방향(reverse). 원형 오빗은 한쪽만, 타원은 양쪽, 직선은 양쪽이 같은 크기.
  - 전제: X-Y 프로브 직교(90°)와 같은 감도. 실제 설치 각도 보정.
- **수식**: G_xy, H1, H2, γ², Full spectrum
- **랩**: LAB-XCH-01 (입력·출력 잡음, 평균 수 → H1 vs H2, 코히어런스), LAB-FULL-01 (X/Y 진폭·위상 → 오빗 + 정/역 성분)
- **과제**: M = 1에서 코히어런스가 왜 항상 1인가? 오빗이 직선일 때 정·역 성분의 비는?
- **원본**: Phase 5 Full spectrum, Phase 7 Coherence

### 3-5 차수추적 (Order Tracking)
- **목표**: 회전수가 변하는 신호를 각도 기준으로 분석한다 (태코가 있을 때와 없을 때).
- **내용**
  - 필요성: Smearing 해결(1-3), 차수 스펙트럼(가로축 = 차수).
  - 계산형 차수추적: 키페이저 시각 → 각도-시간 관계 보간 → 등각도 재샘플링 → FFT. 정수 회전 프레임이면 Uniform 윈도우를 쓸 수 있다.
  - 차수 분해능 = 1/(프레임 회전수), 최대 차수 = (회전당 샘플 수)/2.56.
  - Tacholess: STFT에서 기준 차수의 순시 주파수 추출 → 적분으로 위상 복원 → 재샘플링.
  - 함정 요소: 재샘플링 보간 오차, 회전수 급변.
- **수식**: `\theta(t) = 2\pi\int f_r\,dt`, `\Delta o = 1/N_{rev}`, `o_{max} = (\text{회전당 샘플})/2.56`
- **랩**: LAB-ORD-01 — 런업 신호 → 시간 기반 FFT vs 차수 스펙트럼, 키페이저 유/무, 회전당 샘플 수
- **원본**: 6-1

### 3-6 트래킹 필터 · 노치 필터와 1X 벡터 추출
- **목표**: nX 성분만 뽑아내거나(Bode/Polar/밸런싱의 원천) 제거한다.
- **내용**
  - 트래킹 필터: 키페이저 주파수를 따라 움직이는 좁은 BPF. 디지털로는 복소 복조 + LPF(lock-in): V_1X = LPF{x(t)·e^{−jθ(t)}} → 진폭과 위상을 동시에 얻는다.
  - 대역폭 선택: 좁으면 잡음이 적지만 응답이 느려 런업 중 지연·위상 오차, 넓으면 반대.
  - 노치: 1X 제거 → 서브싱크로너스·비동기 성분 강조. "Not-1X" overall 개념.
  - 1X 필터 오빗 vs 직접(unfiltered) 오빗 (5-3).
- **수식**: `\vec V_{nX}(t) = 2\,\mathrm{LPF}\{x(t)\,e^{-jn\theta(t)}\}`
- **랩**: LAB-FLT-02 — 런업 + 잡음 → 트래킹 필터 대역폭에 따른 1X 진폭·위상 추정, 노치 on/off
- **원본**: 3-2 (Tracking, Notch, Order filter)

### 3-7 엔벨로프 분석 · Spectral Kurtosis · Kurtogram
- **목표**: 구름베어링 초기 결함을 엔벨로프로 찾고, 복조 대역을 Kurtogram으로 정량적으로 정한다.
- **내용**
  - 원리: 결함 충격 → 구조 공진(고주파) 여기 → 충격 반복 주파수로 진폭 변조(1-7 AM) → 복조해서 반복 주파수를 꺼낸다.
  - 절차: BPF(공진 대역) → 포락선(정류 + LPF, 또는 Hilbert 변환으로 |해석 신호|) → DC 제거 → FFT → 엔벨로프 스펙트럼에서 BPFO/BPFI 하모닉과 측대역 확인.
  - 대역 선택이 성패를 가른다 → Spectral Kurtosis(주파수별 첨도: 충격성이 큰 대역일수록 큼), Kurtogram(중심 주파수 × 대역폭 지도, Fast Kurtogram).
  - 벤더 기법(PeakVue, gSE, Spike Energy, SEE): 원리는 HP + 피크/포락 검출. 단위와 수치는 벤더 고유라 서로 비교할 수 없다.
- **수식**: `x_a = x + j\,\mathcal H\{x\}`, `env = |x_a|`, 첨도 `K = E[(x-\mu)^4]/\sigma^4` (정규분포 = 3)
- **랩**: LAB-ENV-01 (BPF 대역 선택 → 엔벨로프 스펙트럼), LAB-SK-01 (Kurtogram → 추천 대역을 ENV-01로 전달)
- **과제**: 일부러 틀린 대역(공진 밖)을 고르면 엔벨로프 스펙트럼이 어떻게 되나? Kurtogram 추천 대역과 비교한다.
- **원본**: 3-2 (Envelope, SK/Kurtogram, 벤더 기법), 말미 제안 ③

### 3-8 켑스트럼 · 자기상관 · 시간영역 특징량
- **목표**: 주기 패밀리(하모닉, 측대역)를 자동으로 찾고, 충격성 지표를 해석한다.
- **내용**
  - 실 켑스트럼 c(τ) = IFFT{log|X(f)|} → quefrency 피크 = 하모닉·측대역 간격의 역수. 기어 측대역 패밀리, 베어링 하모닉 검출.
  - Liftering: 켑스트럼에서 특정 패밀리를 제거하거나 추출. 전달경로 영향 분리.
  - 자기상관: 주기 검출 (회전수를 모를 때, 6-0).
  - 특징량: RMS, Peak, Crest factor, Kurtosis, Skewness. 충격성이 커지면 Kurtosis·CF가 오르지만, 결함이 진행돼 손상이 넓어지면 다시 낮아질 수 있다 → 값 하나가 아니라 추세로 본다.

  - ANC/SANC: 기어 소음 속 베어링 신호 분리 — 개념만.
- **수식**: 켑스트럼, Kurtosis, Crest factor
- **랩**: LAB-CEP-01 (측대역 패밀리 → quefrency 피크), LAB-FEAT-01 (결함 진행 시뮬레이션 → 특징량 추세)
- **원본**: 3-2 (Cepstrum, ANC/SANC, MED, Autocorrelation)

## Part 4. 회전체 동역학 기초

Part 0의 강제진동·불평형 입문(0-4, 0-6) 위에서 먼저 **회전기계의 구성(4-0)**을 정리한 뒤, 회전체만의 현상 — Bode/Polar와 증폭계수, 선회(whirl), 유막 베어링과 안정성 — 을 다룬다. 바로 뒤 Part 5의 오빗·Shaft centerline·Bode/Polar 판독이 이 Part를 쓰고, Part 6~7에서 다시 참조한다 (D-027·D-036).

기대는 곳 (D-034): 4-1은 2-3의 1X 벡터·위상 관례(Contents §3)를, 4-2는 1-1의 복소 표현을 쓴다. Full spectrum(3-4)과 오빗 판독(5-3)은 아직 없으므로 4-2에서는 정/역 성분을 직접 계산해 보여 주고 판독은 그쪽으로 넘긴다. 사이트 제작은 트랙 B(M5)가 Part 3(M4)보다 먼저 할 수 있다.

### 4-0 회전기계의 구성: 무엇이 돌고, 무엇이 받치나? (신규, D-036)
- **목표**: 기계 구성도를 보고 구동기·피동기와 회전부·고정부를 구분하고, 힘이 지지계로 전달되는 경로와 진동 모델의 경계를 설명할 수 있다.
- **내용**
  - 모터·터빈은 구동기, 펌프·팬·압축기는 피동기의 예. 발전기는 기계 에너지를 전기로 바꾼다. 모터는 기계 전체, 로터는 그 안에서 도는 부분이라 서로 같은 분류가 아니다.
  - 로터·고정자·축, 임펠러·블레이드와 케이싱의 관계. 고정부 전체가 반드시 전동기의 고정자인 것은 아니다.
  - 축·커플링·축계, 회전력을 전달하는 토크와 축을 옆으로 미는 힘의 구분. 커플링이 있어도 정렬이 필요하다(진단은 Part 6·8).
  - 구름/유막은 지지 방식, 반경/추력은 하중 방향. 로터 → 베어링 → 하우징/받침대 → 기초의 전달 경로. 하나의 베어링이 두 방향 하중을 함께 받을 수 있다.
  - 자전과 횡/축/비틀림 진동 구분. 선회와 강체/굽힘 모드는 4-2에서 전개한다.
  - MCK의 m·c·k를 물리적 구성과 연결. 무질량 직렬 스프링의 예제로 지지 강성과 고유진동수를 조작하되 실제 축·여러 베어링·기초를 모두 이 식으로 계산하지 않는다.
- **기대는 곳**: P0-1~P0-5의 힘·강성·고유진동수·모드. Part 2는 측정 위치를 되짚을 때만 링크하고 Part 3의 분석 기법은 선행 조건이 아니다.
- **수식**: 직렬 예제 `1/k_eq = 1/k_sh + 1/k_br + 1/k_sup`, `f_n = (1/2π)√(k_eq/m)`
- **랩**: LAB-SUP-01 — 지지 강성·질량 → 등가 강성·고유진동수, 강체 지지 극한과 비교.
- **과제**: 모터-펌프 구성에 회전부/고정부 표시, 베어링 분류의 두 축 구분, 지지 강성을 낮췄을 때 f_n 변화 확인.
- **함정**: 모터와 로터를 기계 종류 둘로 나누기, 모든 베어링 강성을 무조건 더하기, 횡진동과 비틀림을 같은 운동으로 보기, 전기적 결함을 여기서 미리 진단하기.
- **경계**: Part 0 = 진동 원리·기계 요소 주파수, Part 2 = 측정, Part 3 = 분석, Part 4 = 구성·동역학, Part 5 = 판독, Part 6 = 결함 진단. 새 절 때문에 다른 Part를 이동하거나 기존 ID를 바꾸지 않는다.
- **원본**: 없음 (I-027 보완)

### 4-1 1자유도 불평형 응답을 Bode/Polar로 (옛 0-2)
- **목표**
  - 불평형 가진 1자유도 응답을 Bode와 Polar로 그리고 해석할 수 있다.
  - 런업 데이터에서 Half-power법으로 AF를 뽑고 분리여유(Separation Margin)를 계산할 수 있다.
- **내용**
  - 4-0에서 확인한 로터·지지계에 대해 0-6에서 입문으로 본 "진폭·위상 vs rpm"을 정량적으로 읽는다.
  - 불평형 가진은 힘이 Ω²에 비례한다 → 일정 힘 FRF(0-4)와 모양이 다르다. 저속에서 0, 고속에서 m_u·e/M로 수렴한다 (질량중심 둘레로 회전).
  - 위상: 공진에서 90° 지연, 공진을 지나면 약 180°. 고속에서는 heavy spot(불평형 위치)과 high spot(최대 변위 위치)이 반대가 된다 → 밸런싱의 핵심 개념 (8-2).
  - Polar: 같은 1X 벡터(진폭∠위상)를 rpm에 따라 극좌표에 찍은 궤적. 공진은 루프로 보인다 (판독은 5-5).
  - AF = N_c/(N₂ − N₁) ≈ 1/(2ζ), Q factor와 같은 개념 (원본 공식 표기 정정: I-004).
  - 실제 런업 데이터의 오차 요인: rpm 샘플 간격, 잡음, 런아웃 미보상.
  - API 684의 AF·SM 개념 (요구 수치는 원문 대조 후 기재).
- **수식**: 1자유도 불평형 응답, 위상, AF (Contents §3)
- **랩**: LAB-AF-01 Run-up Bode & 증폭계수
- **과제**: 원본 첫 과제 — 런업 데이터에서 AF와 SM 직접 뽑기. ζ를 바꾸고 AF 추정값과 1/(2ζ)를 비교한다.
- **함정**: 감쇠가 크면 진폭 피크 회전수와 위상 90° 회전수가 어긋난다. 런아웃을 빼지 않은 저속 벡터를 그대로 쓴다.
- **원본**: Phase 0 첫 과제

### 4-2 Jeffcott 로터: 회전체 응답의 기본 (신규, 옛 0-3)
- **목표**: 회전체가 비회전 구조와 다른 점(선회·자전, 동기 응답, 임계속도, 고속에서 질량중심의 자기정렬)을 설명할 수 있다.
- **내용**
  - 4-0의 운동 구분에서 출발: 자전(spin)은 축 자체의 회전, 선회(whirl)는 축 중심이 도는 운동. 먼저 강체 병진·기울기와 축 굽힘 도식으로 모드의 차이를 보여 준다.
  - Jeffcott 모델: 질량 원판 + 무질량 탄성축, 등방 강성 k, 감쇠 c.
  - 복소 좌표 z = x + jy(P1-1의 복소 표현)로 쓰면 1자유도 불평형 응답(0-6, 4-1)과 같은 꼴의 방정식이 된다 → 진폭비·위상을 그대로 쓴다.
  - 등방 지지: 원형 오빗, 정방향 동기 선회(forward synchronous whirl).
  - 비등방 지지(k_x ≠ k_y): 타원 오빗, 임계속도가 두 개, 두 임계속도 사이에서 역방향 선회가 나타날 수 있다.
  - 오빗이 원이 아니면 Full spectrum(3-4)에 역방향 성분이 생긴다 (오빗 판독은 5-3).
  - 강체 모드 vs 굽힘 모드, 강성 로터 vs 유연 로터 (운전 속도가 첫 굽힘 임계속도보다 위인가).
- **수식**: `m\ddot z + c\dot z + k z = m e \Omega^2 e^{j\Omega t}`, 비등방일 때 `z = A_f e^{j\Omega t} + A_b e^{-j\Omega t}`
- **랩**: LAB-JEF-01 — k_x, k_y, ζ, 회전수 → 오빗 애니메이션, X/Y 시간파형, 정/역 성분 크기, 두 피크가 있는 Bode
- **과제**: k_y = k_x일 때와 k_y = 1.3 k_x일 때 오빗과 역방향 성분을 비교한다. 두 임계속도 사이에서 프리세션 방향은?
- **함정**: 케이싱 센서 하나로 로터 거동을 판단한다.
- **원본**: 없음 (Phase 10 로터다이나믹스 중 기초만 흡수)

### 4-3 유막 베어링과 안정성 입문 (신규, 옛 0-4)
- **목표**: 회전체가 "스스로" 진동할 수 있는 이유(교차연성 강성), Oil whirl/whip 메커니즘, Log decrement, Campbell 선도의 개념을 설명할 수 있다.
- **내용**
  - 4-0의 유막 지지에서 출발: 회전하는 축이 오일을 좁아지는 간극으로 끌어들여 압력을 만들고 하중을 받친다. 외부 가압 방식과 구별하고 8개 계수 전에 원리를 도식으로 설명한다.
  - 저널 베어링: 간극, 편심률 ε, 자세각(attitude angle). 하중 방향과 직각으로도 축이 움직인다 → Shaft centerline (5-4).
  - 유막 계수 8개(K_xx, K_xy, K_yx, K_yy, C_xx …). 교차연성 K_xy가 선회 방향으로 접선력을 만들어 정방향 선회를 밀어준다.
  - 유막의 평균 원주속도 ≈ 축 표면속도의 절반 → Whirl 주파수 ≈ 0.42~0.48X (손실 때문에 0.5X보다 약간 낮음).
  - Whirl → Whip: 회전수가 첫 임계속도의 약 2배를 넘으면 whirl 주파수가 1st critical에 잠긴다(lock) → 주파수 고정, 진폭 큼, 위험.
  - 안정성: 0-3의 감쇠 자유진동이 줄지 않고 커지는 경우다. 복소 고유치 λ = σ ± jω_d. σ > 0이면 불안정. Log decrement δ = −2πσ/ω_d (δ > 0이면 안정, 작은 ζ에서 δ ≈ 2πζ).
  - 대책 개념: 틸팅패드 베어링(교차연성 ≈ 0), 하중 증가, 오일 온도·점도 조정, 씰 스월 브레이크.
  - Campbell 선도: 회전수 vs 고유진동수 + 차수선(1X, 2X …). 교차점 = 잠재 공진. 자이로 효과로 정/역 모드가 갈라진다.
  - Steam whirl, Alford force, 씰 교차연성도 같은 원리다 (6-3, 7-3, 7-4).
- **수식**: 복소 좌표 `m\ddot z + c\dot z + (k - j k_{xy}) z = 0`, 고유치 λ, `\delta = -2\pi\sigma/\omega_d`. 간단 모델에서 k_xy = cΩ/2로 두면 안정 한계 회전수 ≈ 2ω_n.
- **랩**: LAB-STB-01 — k, c, k_xy(또는 k_xy = cΩ/2 모델), 회전수 → 고유치 궤적, 자유응답 오빗(수렴/발산), Log dec, 안정 한계 회전수, Whirl → Whip 워터폴 미리보기
- **과제**: k_xy를 올리면 언제 Log dec가 0이 되나? 감쇠 c를 2배로 하면 안정 한계는 어떻게 되나?
- **함정**: 서브싱크로너스 성분을 모두 oil whirl로 본다 (러브, 풀림, 유동, 구조 공진일 수도 있다 → 6-3 감별표).
- **원본**: Phase 0 "복소 고유치", Phase 4-1 oil whirl/whip, Phase 10 일부

## Part 5. 현장 플롯 읽기

각 플롯마다 **무엇을 그리나 / 무엇이 보이나 / 무엇을 숨기나 / 판독 패턴**을 정리한다.

### 5-1 시간파형
- 정현파, 맥놀이, AM, 임팩트, 절단(truncation: 러브로 꼭대기가 잘림), 클리핑(센서·ADC 과부하) 구별.
- 위아래 비대칭 파형 → 비선형 (러브, 풀림).
- 키페이저 마커를 겹쳐 사건이 회전당 몇 번인지 센다.
- Crest factor, Pk-Pk. 진폭 스펙트럼이 같아도 파형은 다를 수 있다 (1-1).
- **랩**: LAB-TWF-01 — 파형 패턴 갤러리와 맞히기 퀴즈

### 5-2 스펙트럼 · Waterfall · Cascade
- 스펙트럼 판독 순서: 1X 찾기 → 하모닉 → 서브싱크로너스 → 비동기 → 고주파 대역 → 노이즈 바닥.
- Waterfall/Cascade 판독: 차수선 vs 고정 주파수선. Whirl이 회전수를 따라가다가 1st critical에 잠기면 Whip — 결정적 증거.
- Full spectrum cascade: 정/역 성분의 회전수 의존성.
- **랩**: LAB-WF-01

### 5-3 오빗 (Orbit)
- 직접 오빗 vs 1X 필터 오빗. 키페이저 dot(blank-bright 관례): dot에서 다음 dot 방향으로 프리세션 방향을 판정 → 정방향/역방향.
- 형태: 원(등방), 타원(비등방, 하중), 바나나/8자(미스얼라인 예하중, 2X), 내부 루프(서브싱크로너스), 꽃잎·찌그러짐(러브), 평평한 면(간극 접촉).
- dot 개수: 서브하모닉 1/n X가 안정적이면 dot n개 (원본의 "dot 개수 = 차수"는 이 경우에 해당, I-012). 비정수 차수면 dot이 이동한다.
- **랩**: LAB-ORB-01

### 5-4 Shaft Centerline
- Gap 전압(DC) 변화 → 베어링 간극 원 안에서 축 중심 위치 vs rpm.
- 정상: 저속에서 바닥 → 회전이 오르면 회전 방향 쪽으로 떠오름 (자세각, 4-3).
- 판독: 편심률이 너무 낮음 = 가벼운 하중 → whirl 위험 / 비정상 위치 = 미스얼라인·예하중 / 장기 변화 = 베어링 마모·열팽창.
- 기준: 정지 시 바닥 위치(cold gap)와 직경 간극.
- **랩**: LAB-SCL-01 — 하중·회전수 → 단순 베어링 모델의 편심률·자세각

### 5-5 Bode · Polar · APHT
- Bode: 피크 + 위상 변화가 함께 있어야 공진이다. 피크만 있고 위상 변화가 없으면 공진이 아닐 수 있다.
- Polar: 같은 데이터를 벡터 궤적으로 → 공진은 루프. 모드 식별, 런아웃 보상 효과 확인, 밸런싱 방향을 바로 읽는다.
- 여러 베어링의 Polar 비교 → 모드 형상(병진/원추).
- APHT(Amplitude-Phase-Time): 정속 운전 중 1X 벡터의 시간 추세 → 열 bow, Morton effect, 부하 변화(7-2).
- **랩**: LAB-BODE-01 (LAB-AF-01 확장: 2모드 로터)

### 5-6 트렌드 & 벡터 트렌드
- 스칼라(overall) 트렌드의 한계: 1X 벡터가 회전하기만 하고 크기가 같으면 보이지 않는다.
- 벡터 트렌드, Acceptance region(진폭·위상 허용 영역)으로 변화를 감지한다.
- ISO의 "변화량" 기준과 연결 (9-1).
- **랩**: LAB-TRND-01 — 1X 벡터가 회전하는 시나리오에서 스칼라 vs 벡터 트렌드, Acceptance region

원본 Phase 5의 8가지 플롯과 Full spectrum은 5-1~5-6과 3-4에 모두 포함된다.

## Part 6. 결함별 진단

각 결함마다 **메커니즘 → 증거 5요소 → 감별 → 확인 방법**으로 정리한다.

### 6-0 진단 주파수 지도와 회전수 추정
- 원본 4-1 결함 지도를 증거 5요소 열로 확장한 표 (사이트에서 필터·검색 가능한 표로). 0-7의 "요소 → 주파수" 지도를 거꾸로 쓰는 "주파수 → 원인" 지도다 (D-032).
- 회전수를 모를 때 (원본 6-2): 저주파 하모닉 패밀리, 켑스트럼(3-8), 엔벨로프 측대역 간격, GMF 측대역 간격, BPF/Nb, 자기상관, 스펙트로그램 차수선 기울기 비, 운전 조건 변경(추종 = 회전 관련, 고정 = 구조/전기), 명판 rpm·슬립·기어비 역산.
- **랩**: LAB-FAULT-01 결함 신호 합성기 (Part 10 케이스의 엔진), LAB-RPM-01 회전수 추정

### 6-1 1X 계열: 불평형 · 휨 · 크랙 · 편심 · 공진
- 불평형(정적/커플/동적): 1X 우세, 위상 안정, 수평-수직 위상차 약 90°, 공진 아래에서 진폭 ∝ 회전수².
- 휨축·열변형(bow): 저속에서도 1X. 런아웃은 회전수와 무관하게 일정하고, bow는 회전수가 오르면 동적으로 확대된다.
- 로터 크랙: 1X·2X 벡터의 추세 변화, 1/2 임계속도에서 2X 피크, slow roll 벡터 변화.
- 편심(풀리·로터), 모터 공극 편심(전기적 → 6-6).
- 공진: 1X가 큰데 특정 회전수 범위에서만 크고 위상이 급변 → 구조 공진(8-1).
- 1X 감별 플로우차트.

### 6-2 미스얼라인먼트 · 풀림 · 러브
- 미스얼라인: 1X/2X, 축방향 성분, 커플링 건너 위상 약 180°, 바나나/8자 오빗, Shaft centerline의 비정상 위치(예하중). 원본의 "각 = 축방향, 평행 = 2X"는 단순화다 — 실제로는 섞여 나오고 결정적 증거는 위상과 오빗이다 (I-013).
- 풀림: 구조적 풀림(기초·볼트: 1X 방향성, 부재 간 위상차) vs 회전 풀림(베어링 간극 과다: 0.5X 분수 하모닉, 많은 하모닉, 비선형). 시간파형 비대칭.
- 러브: 부분 러브(1/2X·1/3X 분수 하모닉 + 하모닉, 오빗 찌그러짐, 역방향 성분), 전체 원주 러브(dry whirl/whip: 역방향, 위험), 열적 러브(마찰열로 bow → 1X 벡터가 천천히 회전, Newkirk effect).

### 6-3 유체막 · 유체력 불안정
- Oil whirl(0.38~0.48X, 회전수 추종) / Oil whip(1st critical에 잠김). 감별: Cascade에서 회전수 변화에 대한 거동, 내부 루프 오빗 + dot 이동, 정방향.
- Steam whirl(ST): 부하 의존, 부하 임계값(7-3).
- 씰·공력 교차연성: 부하·압력 의존.
- **서브싱크로너스 감별표**: Oil whirl vs Whip vs 러브 vs 풀림 vs Rotating stall vs 구조 공진 (원본 말미 제안 ② 반영).
- 대책 개념은 4-3. **랩**: LAB-WF-01 프리셋, LAB-STB-01

### 6-4 구름베어링
- 개요(세는 규칙, FTF ≈ 0.4X, BPFO = N_r·FTF)는 0-7. 여기서는 결함 주파수 식 (원본 4-2), 경험칙 BPFO ≈ 0.4·n·f_r, BPFI ≈ 0.6·n·f_r, FTF ≈ 0.4·f_r. 슬립으로 ±1~2 % 어긋남. BSF 1×/2× 관례(I-008).
- 결함 위치별 패턴: 외륜(BPFO 하모닉, 하중영역 고정 → 측대역 적음), 내륜(BPFI + 1X 측대역, 하중영역 통과 AM), 볼(2×BSF + FTF 측대역), 케이지(FTF, 서브싱크로너스).
- 고장 4단계와 단계별 유효 기법 (원본 + 보강): 1단계 초음파·엔벨로프 → 2단계 부품 공진 여기 → 3단계 결함 주파수 + 하모닉·측대역 → 4단계 노이즈 바닥 상승, 1X 증가, 결함 주파수가 오히려 흐려짐.
- **랩**: LAB-BRG-01 — 결함 주파수 계산기 + 단계 시뮬레이터

### 6-5 기어
- GMF = z × f_r (0-7). 측대역 간격 = 결함 축의 회전수. 헌팅 투스 주파수 f_HT = GMF / LCM(z₁, z₂).
- 패턴: 마모(GMF 하모닉 증가, 고유진동수 여기), 편심(GMF ± 1X 측대역), 국부 결함·깨진 이(회전당 1회 충격 → 많은 측대역, TSA로 선명), 백래시.
- 도구: TSA(1-5, Residual/Difference), 켑스트럼(3-8).
- **랩**: LAB-GEAR-01

### 6-6 전기적 원인 (모터 · 발전기)
- 2×LF 진동: 자기력은 전류의 제곱에 비례 → 전원 주파수의 2배. 고정자 문제, 공극 편심(정적 → 2×LF, 동적 → 2×LF ± 극통과 주파수 측대역).
- 유도전동기: 동기속도 f_sync = 2·LF/P(P: 극수), 슬립 주파수 = f_sync − f_r, 극통과 주파수 PPF = P × 슬립 주파수. 로터바 결함 → 1X ± PPF 측대역.
- 2극 동기 발전기: 1X = LF, 2X = 2×LF → 주파수로는 분리 불가 → 트립 시 순간 소멸 여부, 계자 전류 변화 응답으로 구분.
- 샤프트 전압·전류, 베어링 전식(fluting).
- **랩**: LAB-MOD-01 프리셋 (극통과 측대역, 유도전동기 2X vs 2×LF 맥놀이)

### 6-7 유체 · 공력 원인
- 블레이드/베인 통과 주파수(Nb × X, Nv × X): 유량·간극·손상에 따라 변화.
- Rotating stall(압축기): 회전하는 실속 셀 → 서브싱크로너스 성분 (셀 속도는 로터 속도의 일부, 문헌마다 범위가 다름). Surge: 매우 낮은 주파수의 큰 유량 맥동.
- 캐비테이션(펌프): 광대역 고주파 랜덤.
- 연소 동역학(GT): 동압 센서, 수백~수천 Hz, 음향 모드(종방향/원주방향) — 상세는 7-4.

### 6-8 비틀림 진동 · 블레이드 진동
- 비틀림: 횡진동 센서로는 거의 안 보인다. 측정은 기어 이·키페이저 펄스 간격 변동(순시 각속도), 스트레인 게이지/텔레메트리.
- 원인: 계통 외란(단락, 재폐로), SSR(직렬 보상 송전선의 전기 공진과 축계 비틀림 모드 결합), 인버터 맥동. Holzer법으로 비틀림 고유진동수 — 개념만.
- 블레이드: Campbell 선도(원심 강성화로 rpm에 따라 오르는 고유진동수 + 엔진 차수선 → 교차점 = 공진 위험), 측정은 BTT/NSMS·스트레인 게이지.
- **랩**: LAB-CAMP-01 Campbell 선도

## Part 7. GT/ST 특화 현상

각 현상마다 **현상 → 메커니즘(Part 4·6 링크) → 데이터에서 어떻게 보이나 → 운전 대응**으로 정리한다.

### 7-1 기동·정지와 임계속도 통과
- 1st/2nd 굽힘 임계속도, 강체 모드. 통과 시 위상 반전(약 180°, 실제로는 모드와 센서 위치에 따라 다름).
- 런업 vs 코스트다운 비교: 열 상태와 조건이 달라 Bode가 다르게 나온다.
- 통과 진폭을 키우는 요인: 잔류 불평형 + bow. 트립 배율(2-5).
- AF/SM 평가(4-1). **랩**: LAB-BODE-01 프리셋

### 7-2 Thermal bow · Turning gear · Morton effect
- 정지 중 상하 온도차 → 휨 → 기동 시 1X 큼. 터닝 기어로 균일화하고 편심(eccentricity) 측정으로 확인한 뒤 기동한다.
- 정속 중 1X 벡터 변화 → APHT(5-5).
- Morton effect: 저널 원주의 비균일 가열(오빗의 hot spot) → 열 bow → 1X 벡터가 수 분~수 시간 주기로 천천히 선회, 진폭이 커지는 루프. Polar/APHT에서 원·나선 궤적, 부하·오일 온도 영향.
- Newkirk effect(러브 마찰열, 6-2)와 구별: 접촉 여부.
- **랩**: LAB-TRND-01 프리셋 (Morton: 벡터 선회)

### 7-3 ST 특화
- Steam whirl/whip: 부하 증가 → 서브싱크로너스 발생, 부하 임계값(threshold load). 노즐 분사력 비대칭, 씰 교차연성.
- Partial arc admission: 밸브 시퀀스 → 증기력 방향 → 베어링 하중 변화 → Shaft centerline 이동, 편심률 저하 → 안정성 저하.
- 차열팽창(differential expansion), 축방향 위치(thrust), eccentricity 감시의 의미와 한계.
- 대형 다축 ST: catenary alignment, cold-hot alignment, 베어링 하중 분배.
- **랩**: 시나리오 프리셋 (부하 슬라이더 → Shaft centerline과 서브싱크로너스)

### 7-4 GT 특화
- Alford force: 터빈 팁 간극 변화 → 교차연성 (4-3 원리).
- 압축기 rotating stall/surge(6-7), 동압 신호.
- 연소 동역학: 동압 센서, 종방향/원주방향 음향 모드, 연소 튜닝과의 관계.
- 액세서리 기어박스: 구름베어링·기어(6-4, 6-5), TSA 필요.
- 블레이드 진동(6-8), 이물질 손상(FOD) → 1X 벡터 급변.

### 7-5 발전기와 축계
- 2×LF 코어 진동, 엔드와인딩 공진(2×LF 근처 고유진동수).
- 계자 열 민감도(field thermal sensitivity): 계자 전류에 따라 1X가 변함 → 계자 전류 변경 시험으로 확인.
- 샤프트 전압·전류(접지 브러시).
- 비틀림, SSR(6-8). 터빈-발전기 커플링 미스얼라인(6-2).

## Part 8. 구조 시험 · 밸런싱 · 정렬

### 8-1 구조 공진 판별과 임팩트 시험
- 운전 중 공진 의심 신호: 특정 회전수 범위에서만 큼, 방향성이 강함, 위상 급변.
- 범프 테스트: 정지 중 / 운전 중(동기 성분의 영향을 평균으로 줄이는 기법).
- 임팩트 시험 절차: 해머 팁 경도(→ 가진 대역), Force/Exponential 윈도우(1-4), 트리거, 더블 히트 검출, 평균 3~5회, 코히어런스(3-4).
- Half-power로 ζ, Q 추정. ODS: 운전 중 여러 점의 진폭·위상(기준 센서 대비) → 변형 형상.
- 공진 vs 강제진동 구별: 속도 변화 시 추종 여부, 위상 거동.
- Soft foot(볼트를 풀며 진동·변위 변화 확인), 기초 강성, 배관 반력.
- **랩**: LAB-HPB-01 — FRF 피크 → Half-power ζ, 지수 윈도우의 ζ 과대 효과, 해머 팁에 따른 가진 스펙트럼

### 8-2 밸런싱
- 1면 영향계수법: H = (V₁ − V₀)/W_t, 보정추 W_c = −V₀/H (모두 복소수).
- 2면: 2×2 복소 행렬. 시험추 크기 선정(응답이 의미 있게 변하도록).
- 4-run법(위상 없이 진폭만으로 작도).
- 모달 밸런싱(유연 로터): 모드별 추 세트(대칭/비대칭 배치).
- 분할추(split weight), 고정 위치에 나눠 달기.
- 밸런스 등급: ISO 21940-11(구 ISO 1940-1) G 등급, e_per = G/Ω.
- 현장 트림 밸런싱 vs 공장(저속/고속) 밸런싱. 위상 관례(2-3)와 heavy spot–high spot 지연각(4-1) 주의.
- **랩**: LAB-BAL-01 — 숨은 불평형이 있는 가상 로터 → 시험추 → 영향계수 → 보정추 → 잔류 진동

### 8-3 정렬
- 오정렬 종류(평행/각)와 회전수에 따른 허용 기준.
- 측정법: 다이얼 게이지(rim-face, reverse) → 레이저.
- 열성장 보정(cold offset), hot alignment 확인(프록시미티 gap 변화, 광학 측정).
- Soft foot을 먼저 잡는다.
- **랩**: LAB-ALN-01 (선택) 정렬 계산기

## Part 9. 규격 · 판정 · 진단 절차

규격 수치의 인용 범위는 I-009 정책을 따른다.

### 9-1 진동 판정 규격 (ISO 20816 계열)
- 구성: Part 1(일반), Part 2(대형 육상 GT/ST/발전기), Part 3(산업용 기계), Part 5(수력) 등. 축 진동과 비회전부 진동의 평가량 차이(구 ISO 7919 vs 10816).
- Zone A/B/C/D의 의미, 평가량(광대역 속도 rms, 축 상대 변위 pp).
- 변화 기준: 기준값 대비 변화가 Zone B 상한의 25 %를 넘으면 의미 있는 변화 (원본 Δ25 %).
- 알람/트립 설정 원칙: 기준선 + 변화량, Zone 경계 활용.
- **랩**: LAB-ISO-01 — 측정값·기계 분류 → Zone 판정 (경계값은 사용자가 보유 규격에서 입력)

### 9-2 API 규격 요점
- API 670(보호 시스템) → 2-5
- API 684(로터다이나믹스 튜토리얼: AF, SM, 안정성 해석 레벨) → 4-1, 4-3
- API 612(ST), 616(GT), 617(압축기): 운전 시험 진동 허용 개념 (수치는 원문 대조 후)

### 9-3 진단 절차와 보고
- ISO 13373 흐름의 개념: 데이터 수집 → 비교(기준선/규격/추세) → 이상 감지 → 진단 → 예측 → 권고.
- 진단 전 정보 수집: 기계 구성(축 수, 베어링 종류, 기어 잇수, 블레이드 수), 운전·정비 이력, 운전 조건.
- 가설-검증 루프: 증거 5요소로 후보를 좁히고 확인 시험(속도·부하 변경, 전원 차단, 임팩트)을 설계한다.
- 보고서 구성: 요약·권고 먼저 → 데이터와 근거 → 확신도 → 다음 조치.
- 자격 체계: ISO 18436-2 CAT I~IV, Vibration Institute — 간단 소개.

## Part 10. 종합 진단 연습 (캡스톤)

### 10-1 가상 기계 케이스
- LAB-CASE-01: 사이트가 숨은 결함(1~2개)을 가진 가상 기계 데이터를 만든다 (기계 구성표 제공) → 사용자가 측정 설정 → 플롯 선택 → 진단 제출 → 정답과 해설.
- 난이도: 단일 결함 → 복합 결함 → 측정 문제 섞임(진짜 결함 vs 센서·설정 오류).
- 케이스 예: 불평형 vs 구조 공진, Oil whirl → whip, 외륜 결함 2단계, 깨진 기어 이, 2극 발전기 1X vs LF, Morton effect, Slow roll 미보상 착시, AAF 없는 측정의 가짜 피크.

### 10-2 공개 데이터셋 실습
- CWRU 등 (라이선스·용량 확인 후, R-10). 엔벨로프·SK로 결함을 찾고 정답과 비교한다.

### 10-3 현장 데이터 복기 가이드
- 회사 데이터는 저장소에 올리지 않는다. 브라우저에서 로컬 파일을 열어 서버 전송 없이 분석하는 방식을 검토한다.
- 복기 절차 템플릿: 기동/정지 Raw waveform → Bode/Cascade 재생성 → 당시 판단과 비교.
