### P10-2 API 규격 요점
- [필수] 111 AF와 SM의 관계를 설명하지 않는다("API 684 계열에서 찾고"). ### P10-3 진단 절차와 보고
- [필수] 사례 논리(17·161·163): 같은 3000 rpm에서 **시간에 따라** 20 → 40 µm로 늘었다는 관측을 "속도별로 3000에서 봉우리 → 공진 후보"로 설명한다. 공진이 원래 3000 근처였다면 전에도 컸어야 하므로 공진만으로는 "변화"를 설명하지 못한다. 가를 질문은 "무엇이 변했나": (가) 봉우리 자리는 그대로·높이만 2배 → 가진(불평형·휨) 증가, (나) 봉우리가 3000 쪽으로 옮겨옴 → 지지 강성 저하(풀림·소프트 풋·크랙)로 고유진동수 이동. 예전 기동/정지 Bode와 지금 것을 겹친 그림(두 가설의 예측 곡선 + 관측 3점)이면 권고 "기존 기동/정지 자료 확인"의 이유가 그대로 보인다.
- [권장] 20·40·20 µm 대칭 3점은 불평형(ω² 가진) 공진과 맞지 않는다 — 1자유도로 2400에서 봉우리의 반이 되려면 ζ ≈ 0.18이고, 그러면 3600에서는 봉우리의 0.84배(≈ 34 µm)다. 위 그림을 계산 곡선으로 그리면 같이 풀린다.
- [권장] "1X 변위 Peak"(17·69·161): P10-1은 축 상대 변위를 p-p로 강조했고, 프로브(축)인지 하우징인지도 밝히지 않는다 → "축 상대 1X 변위 p-p"로.
- [필수] 127 "밸런싱·정렬의 자세한 절차는 해당 페이지가 공개되면 연결" — P9-2는 2026-10-12 공개(73304d5) → P9-2 링크, P9-3만 위치로.
