#### LAB-BAS-01 정현파의 세 숫자 (진폭 · 주파수 · 위상)
- P0-2 · M1.T2, M2.2 · 검토 (`SineBasicsLab`, P1-0에서 이동 완료, D-027)
- 목적: 정현파 하나가 진폭·주파수·위상 세 숫자로 정해지고, 세 숫자가 서로 독립이라는 것을 체감한다. 위상을 시간 어긋남 Δt로 읽는다.
- 신호: A·cos(2π f t + φ), 표시 0~1 s. 비교용 기준 파형(A = 1, φ = 0°) 점선
- 조작: A (0.2~2), f (1~20 Hz), φ (−180°~180°, 15° 간격), 기준 파형 표시 토글
- 출력: 시간파형. 읽음값 — 주기 T, 1초당 반복 횟수, Peak, 기준 대비 앞섬/늦음
- 수식: x(t) 대입식, T = 1/f, Δt = (φ/360°)·T (φ > 0 앞섬, φ < 0 늦음)
- 실험 과제: f 5 → 10 Hz에서 T와 물결 수, φ = −90°의 늦음 시간, φ = 180° = 부호 반대, A를 바꿔도 T 불변
- 검증: f = 5 Hz, φ = −90° → Δt = −0.05 s

#### LAB-BAS-02 진폭을 숫자 하나로 (Peak · Pk-Pk · RMS · Crest factor)
- P1-0 · M1.T2, M2.9 · 검토 (`AmplitudeMeasuresLab`, M2.9에서 네 모양·배율의 숫자 해석 보완; 랩 구현은 유지)
- 목적: 같은 Peak라도 모양에 따라 RMS가 다르고, RMS = Peak/√2 환산은 정현파 하나일 때만 맞는다는 것을 확인한다.
- 신호: 네 모양 모두 Peak = 1로 정규화 후 크기 배율을 곱함 — 정현파 5 Hz / 5 Hz + 15 Hz(0.6) / 사각파 / 0.1 s마다 감쇠 충격(180 Hz, τ = 4 ms) + 작은 5 Hz. 0.4 s, 4000점
- 조작: 신호 모양, 크기 배율 (0.5~3)
- 출력: 시간파형 + ±Peak 점선, RMS 실선. 읽음값 — Peak, Pk-Pk, RMS(직접 계산), CF, Peak/√2, 환산 오차 [%]
- 수식: x_rms = √(mean x²), CF = Peak/RMS, 정현파 가정 환산
- 검증 (배율 1): RMS / CF / 환산 오차 — 정현파 0.707 / 1.41 / 0 %, 두 정현파 0.516 / 1.94 / +37 %, 사각파 1.000 / 1.00 / −29 %, 충격 0.136 / 7.36 / +420 %

  - (c) 패딩 전후 스펙트럼 겹쳐 보기

- 검증: 사각파(진폭 1) 하모닉 진폭 = 4/(nπ), Parseval, 정수배 제로패딩 시 원래 bin 위치의 값이 패딩 전과 같음

#### LAB-SMP-01 샘플링 & 에일리어싱
- P1-2 · M1.5 · 완료
- 목적: f_s가 신호 주파수의 2배보다 작으면 다른 주파수로 보인다는 것을 시간영역과 주파수영역에서 동시에 체감한다.
- 신호: 정현파 f = 60 Hz, A = 1 (선택: 두 번째 정현파)
- 조작: f (1~2000 Hz), f_s (20~5000 Hz), 위상 φ, 표시 길이(주기 수), 표시 토글 [참 신호 / 샘플 점 / 샘플이 그리는 신호]
- 출력
  - 시간영역: 참 신호(연속선) + 샘플 점 + 샘플이 그리는 에일리어스 정현파(점선)
  - 접힘 그림: 0~3 f_s 축 위의 f 위치와, 0~f_N으로 접혀 들어오는 지그재그 경로
  - 스펙트럼: 0~f_N, 실제 나타나는 피크
  - 읽음값: 입력 f / 이론 f_a / 측정 피크 주파수
- 수식: 나이퀴스트, 에일리어스 주파수 (§3)
- 실험 과제
  1. f_s = 1000 Hz, f = 60 Hz → 예측: 60 Hz. 확인.
  2. f = 940 Hz, 1060 Hz로 바꾸면? → 둘 다 60 Hz로 보인다. 샘플 점이 60 Hz 정현파 위에 놓이는 것을 시간영역에서 확인.
  3. f = f_s/2 정확히, 위상 φ를 0°↔90°로 → 위상에 따라 진폭이 0까지 사라진다. 나이퀴스트 "미만"이어야 하는 이유.
- 검증: f_s = 1000 Hz에서 f = 940, 1060, 1940 Hz → f_a = 60 Hz. 샘플값이 에일리어스 정현파 값과 일치 (접힘 방향에 따른 위상 반전 포함).

#### LAB-SMP-02 AAF와 f_s = 2.56 F_max
- P1-2 · M1.6 · 완료
- 목적: 상용 분석기가 왜 f_s = 2.56 F_max를 쓰는지, AAF가 없으면 무엇이 들어오는지 본다.
- 신호: 대역 안 성분(예: 0.3 F_max) + 대역 밖 성분(예: 1.8 F_max, 진폭 가변)
- 조작: F_max, 비율 f_s/F_max (2.0~4.0, 기본 2.56), AAF on/off, AAF 형태 [이상적 / Butterworth n차 (2~10)], 차단주파수 = F_max
- 출력
  - 주파수 축: AAF 응답(dB), F_max · f_N · (f_s − F_max) 표시, 접혀 들어오는 구간 음영
  - 스펙트럼: 0~F_max(표시 영역), F_max~f_N(버리는 영역, 회색)
  - 읽음값: 대역 밖 성분이 나타나는 위치와 크기 (AAF 감쇠 반영)
- 수식: `f_s = 2.56 F_max`, `f_s − F_max = 1.56 F_max`(이보다 높은 성분은 0~F_max로 접혀 들어옴), `|H(f)| = 1/\sqrt{1 + (f/f_c)^{2n}}`, `N/2 = 1.28 LOR`(나머지 0.28 LOR 라인은 표시하지 않음)
- 실험 과제
  1. AAF off, 1.8 F_max 성분 → 예측: 어디에 나타날까? → (2.56 − 1.8) F_max = 0.76 F_max에 가짜 피크
  2. AAF on, Butterworth 8차 → 1.8 F_max 성분이 몇 dB 줄었나? (≈ 41 dB)
  3. 비율을 2.0으로 낮추면 같은 필터로는 무엇이 문제인가? (전이대역이 없어 이상적 필터가 필요)
- 검증: F_max = 1000 Hz, f = 1800 Hz → 760 Hz에 나타남. Butterworth 8차, f/f_c = 1.8 → 감쇠 40.8 dB.

#### LAB-SMP-03 ADC & 입력 레인지
- P1-2 · M1.6 · 완료
- 목적: ADC 비트 수와 입력 레인지 설정이 잡음 바닥과 클리핑에 미치는 영향을 본다.
- 신호: 큰 톤(A = 1) + 작은 톤(−40~−140 dB)
- 조작: 비트 수 (8~24), 입력 레인지 (신호 피크 대비 0.5~100배), 확대 보기
- 출력: 양자화된 시간파형(확대), dB 스펙트럼 + 이론 양자화 잡음 바닥선, 클리핑 시 생기는 하모닉 표시, 읽음값: 유효 동적범위
- 수식: `SNR \approx 6.02\,b + 1.76` dB (풀스케일), 레인지 여유만큼 감소 `SNR_{eff} = 6.02\,b + 1.76 - 20\log_{10}(\mathrm{Range}/A_{pk})`. bin당 잡음 바닥은 FFT 처리 이득 `10\log_{10}(N/2)`만큼 더 낮다.
- 실험 과제
  1. 16 bit에서 −100 dB 성분이 보이나? 레인지를 신호의 10배로 잡으면?
  2. 레인지를 신호 피크의 0.8배로 하면 시간파형과 스펙트럼에 무엇이 생기나? (평평한 꼭대기, 홀수 하모닉)
- 검증: 풀스케일 정현파의 양자화 SNR ≈ 6.02b + 1.76 dB (허용오차 명시)

#### LAB-RES-01 분해능: 두 성분 분리
- P1-3 · M1.7 · 완료
- 목적: Δf·T·N의 관계와 "가까운 두 성분을 분리하려면 측정 시간이 길어야 한다"를 체감한다.
- 신호: 두 정현파 f₁, f₂ (진폭 A₁, A₂) + 약한 잡음
- 조작: F_max (100 / 200 / 500 / 1000 / 2000 / 5000 Hz), LOR (100~6400), f₁, f₂, A₁, A₂, 윈도우 [Uniform / Hann], bin 막대 표시, 현장 프리셋
- 프리셋 (2026-10-02 M1.T2 수정 — 이전 본문의 "1X 59.5 Hz vs 2LF 60 Hz"는 오류: 60 Hz 전력망의 2LF = 120 Hz)
  - (a) 간격 3.6 Hz: 25.2 Hz vs 28.8 Hz (기본값, F_max 1000 Hz, 400 → 1600 라인에서 갈라짐)
  - (b) 2극 유도전동기: 2X 119 Hz vs 2LF 120 Hz (간격 1 Hz, F_max 500 Hz에서 3200 라인 필요)
  - (c) 2극 동기기: 2X = 2LF = 120 Hz → 같은 주파수라 분리 불가 (전원 차단 시험 등)
  - (d) 저속 축(1X = 5 Hz): 36 Hz vs 41 Hz (간격 = 1X)
- 윈도우별 필요 간격: `minSeparationBins` — 윈도우 없음 2, Hann 3.5, Flat top 8 bin (본문 P1-3 §2.1 표와 같음)
- 출력: 스펙트럼(bin 막대/선), 계산 패널(Δf, T, N, f_s), 분리 판정(두 피크 사이 골 깊이 dB, |f₁ − f₂|/Δf = 몇 bin)
- 수식: 분해능 3식, `분리 bin 수 = |f₁ − f₂| / Δf`
- 실험 과제
  1. 원본 과제: F_max 1000 Hz, 3200 line → Δf와 T는? (예측 후 확인)
  2. 프리셋 (c)에서 두 성분이 처음 분리되는 LOR은? Uniform과 Hann에서 다른가? F_max를 100 Hz로 낮추면?
  3. 프리셋 (d)에서 측대역을 보려면 LOR이 최소 얼마인가? 그때 T는?
- 검증: F_max 1000 Hz, LOR 3200 → Δf 0.3125 Hz, T 3.2 s, N 8192, f_s 2560 Hz

#### LAB-RES-02 Smearing: 변하는 회전수
- P1-3 · M1.7 · 완료
- 목적: 측정 시간 T 동안 회전수가 변하면 피크가 퍼진다 → 분해능을 무작정 높일 수 없는 이유 (차수추적 P3-5 예고)
- 신호: 코스트다운 1X 처프. 시작 rpm₀, 감속률 a [rpm/s] (선택: 2X 추가)
- 조작: rpm₀, a, F_max, LOR, 윈도우
- 출력: 한 프레임의 스펙트럼(퍼진 피크), 프레임 동안의 rpm 변화 표시, 같은 조건의 정속(a = 0) 스펙트럼 겹쳐 보기

- 실험 과제: 원본 과제 — F_max 1000 Hz, 3200 line(T = 3.2 s)에서 감속률 60 rpm/s로 코스트다운하면 프레임 동안 1X가 얼마나 변하나? (3.2 Hz, 약 10 bin에 퍼짐). LOR을 낮추면 어떻게 되나?
- 검증: 위 수치

#### LAB-ZOOM-01 Zoom FFT
- P1-3 · M1.8 · 완료
- 목적: 좁은 대역을 확대해 고분해능을 얻는 방법과 그 대가(측정 시간)를 본다.
- 신호: 기어 GMF 1200 Hz ± 1X(5 Hz) 측대역 + 잡음
- 조작: 기본 F_max·LOR, Zoom 중심 주파수, 확대 배율 Z (2~64)
- 출력: 기본 스펙트럼(측대역이 안 갈라짐) vs Zoom 스펙트럼(갈라짐), 필요한 원 데이터 길이 T, 처리 단계 그림 (복조 → LPF → 데시메이션 → FFT)
- 수식: Zoom 대역폭 `B = F_{max}/Z`, `\Delta f = B/\mathrm{LOR}`, `T = 1/\Delta f`
- 실험 과제: 측대역을 분리하는 최소 배율은? 그때 T는 기본 측정의 몇 배인가?
- 검증: 배율 Z에서 Δf = F_max/(Z·LOR), 톤 진폭 보존

#### LAB-WIN-01 누설과 가리비 손실
- P1-4 · M1.10, M1.T2 · 완료 (2026-10-02 M1.T2 보완)
- 목적: 성분이 bin 중심에서 벗어나면 (1) 에너지가 옆 bin으로 새고(누설, Spectral Leakage) (2) 가장 높은 막대가 깎인다(가리비 손실, Scallop Loss — 피켓 펜스 효과 때문). 윈도우가 이 둘을 어떻게 바꾸는지 본다.
- 신호: 단일 정현파 f = 60 + δ Hz, A = 1 (f_s = N = 1024 → Δf = 1 Hz, 본문 그림과 같은 조건)
- 조작: δ (0~0.5 bin), 윈도우 [윈도우 없음(Uniform) / Hann / Flat top / Blackman-Harris], dB로 보기
- 출력
  - 시간파형: 1초 프레임 전체의 원래 신호 + 곱한 신호 + 윈도우 가중치 (곱한 신호의 바깥 모양 = 윈도우)
  - 스펙트럼: 48 ~ 72 Hz 막대(Peak), dB 보기에서는 30 ~ 90 Hz 선+점
  - 읽음값: 성분 주파수, 가장 높은 막대, 가리비 손실 dB, 10 bin 떨어진 곳(70 Hz)의 크기 dB(−120 dB 하한)
- 수식: f = 60 + δΔf, 가리비 손실 = 20 log₁₀(가장 높은 막대 / 1)
- 실험 과제: δ = 0에서 모든 윈도우 1.000 / δ = 0.5에서 Uniform 0.64·−29 dB, Hann 0.85·−69 dB, Flat top 0.999 / dB 보기로 Uniform vs Blackman-Harris

#### LAB-DAMP-01 감쇠 자유진동
- P0-3 · M2.3 · 검토 (`DampingLab`)
- 목적: 감쇠비 ζ가 진폭이 줄어드는 빠르기를 정하고 박자는 거의 바꾸지 않는다는 것, 연속 피크 비로 ζ를 읽을 수 있다는 것을 본다.
- 신호: 부족감쇠 `x(t) = x_0 e^{-\zeta\omega_n t}\left(\cos\omega_d t + \dfrac{\zeta\omega_n}{\omega_d}\sin\omega_d t\right)` (v₀ = 0), ζ ≥ 1이면 임계·과감쇠 해. f_n 기본 5 Hz
- 조작: ζ (0~1.5, 기본 0.05), f_n (1~20 Hz), x₀, 포락선 표시, 피크 표시
- 출력: 파형 + 초기조건을 반영한 포락선 ±Ae^(−ζω_n t), 같은 방향의 양의 피크. 읽음값 — ω_d/ω_n, 그려진 파형의 첫 두 피크에서 잰 피크 비·대수감쇠율 δ(이론값과 비교), δ로 추정한 ζ vs 설정 ζ, 진폭이 절반이 되는 주기 수. ζ ≥ 1에서는 비진동 해와 해당 없음(—) 표시
- 검증: ζ = 0.05 → δ = 2πζ/√(1−ζ²) = 0.3146, ω_d/ω_n = 0.99875, 반감 주기 수 = ln 2/δ ≈ 2.2. ζ = 1, x₀ > 0, v₀ = 0 → 부호가 바뀌지 않고 0으로 복귀

- 과제: 지지 1→0.25 MN/m에서 f_n 변화, 지지 4 MN/m 비교, m 100→200 kg일 때 1/√2배.
- 검증: 기본 k_eq = 400000 N/m·f_n = 10.06584242 Hz; k_sup = 250000 N/m → k_eq = 181818.1818 N/m·f_n ≈ 6.78639 Hz; 지지 무한대 → k_eq = 666666.6667 N/m·f_n ≈ 12.99495 Hz. 해석해·단조성·범위 오류 테스트.
- 배치: 구성→MCK 도식 뒤, 따라 하기 → 랩 → 숫자 해석. 안정성·임계속도·운전 진폭은 계산하지 않는다.

#### LAB-JEF-01 Jeffcott 로터: 선회와 오빗
- P4-2 · M5.2 · 사양 (2026-10-06 Claude, D-034 — 트랙 B 구현)
- 목적: 회전체의 응답을 축 단면이 그리는 궤적(오빗)으로 보고, 등방 지지면 원형 정방향 선회, 비등방이면 타원·임계속도 2개·두 임계속도 사이의 역방향 선회가 생긴다는 것을 본다.
- 모델 (`lib/rotor/jeffcott.ts`, 해석해): `m\ddot x + c\dot x + k_x x = m e \Omega^2\cos\Omega t`, `m\ddot y + c\dot y + k_y y = m e \Omega^2\sin\Omega t` (감쇠는 두 방향 같게). 정/역 성분 A_f·A_b는 §3 식
- 조작: 회전수 (0 ~ 2.5 N_x), k_y/k_x (1 ~ 1.6, 기본 1), ζ (0.01 ~ 0.2, 기본 0.05), 재생/정지 (오빗 위 점이 도는 애니메이션 — 표시용으로 느리게, 재생할 때만)
- 출력: 오빗(X-Y, 정방향 파랑·역방향 주황, 회전 방향 화살표, 키페이저 점), X·Y 시간파형, 진폭 X·Y vs rpm(두 피크) + 현재 점, ∣A_f∣·∣A_b∣ vs rpm. 읽음값 — 두 임계속도, X·Y 진폭·위상, ∣A_f∣, ∣A_b∣, 선회 방향
- 수식: 운동방정식, 등방 해 = P4-1의 불평형 응답, z = A_f e^{jΩt} + A_b e^{−jΩt}
- 실험 과제: k_y = k_x와 1.3 k_x의 오빗·역방향 성분 비교 / 두 임계속도 사이에서 선회 방향은? / ζ를 키우면 역방향 구간은?
- 검증 (§6): 등방 → A_b = 0, 원형 오빗, 반지름 = 1자유도 불평형 응답 / ζ = 0이면 두 임계속도 사이에서 ∣A_b∣ > ∣A_f∣
- 주의: Full spectrum(P5-3)·오빗 판독(P6-3)보다 앞이므로 정/역 성분은 페이지에서 직접 계산해 보여 주고 판독은 그쪽으로 넘긴다.
