## I-005 [콘텐츠] 평균화 "랜덤 노이즈는 √N로 감소" 표현
- 등록: 2026-10-02 · Claude
- 원본 (1-4): Linear 평균에서 "랜덤 노이즈는 √N로 감소"
- 검토: 평균 방식에 따라 줄어드는 것이 다르다.
  - **RMS(파워) 평균**: 잡음 바닥의 *평균 레벨*은 그대로이고, 바닥의 *흔들림(표준편차)*만 1/√M로 줄어든다. 스펙트럼이 매끈해져서 읽기는 쉬워지지만 톤 대 잡음비 자체는 개선되지 않는다.
  - **벡터(트리거 동기) 평균, TSA**: 트리거와 동기되지 않은 잡음의 *진폭 자체*가 1/√M로 줄어든다. 톤 대 잡음비가 개선된다.
- 처리: LAB-AVG-01에서 두 방식을 나란히 보여주고 본문에서 구분한다 (Contents §5에 반영함).
  - 2026-10-02 Codex: 본문 숫자 예와 코어 테스트로 RMS 평균 레벨 유지·1/√M 흔들림·벡터 파워 1/M 구분. D-024 본문 검토 대기, 랩 연결 뒤 해결 확인.
- **해결**: 2026-10-02 (Claude, M1.T2). P1-5 그림 2·3(파워 평균: 바닥 높이 유지, 흔들림 1/√M)과 그림 5(트리거 벡터 평균: 바닥 약 1/8)로 구분하고, LAB-AVG-01을 연결했다. 바닥보다 작은 32 Hz 성분은 파워 평균으로 안 드러나고 벡터 평균으로 드러나는 것을 그림·랩·테스트(`figures-p1-4-5.test.ts`)로 확인.

## I-008 [콘텐츠] BSF 정의 관례 (1× / 2×)
- 등록: 2026-10-02 · Claude
- 원본 (4-2): `BSF = (D/2d)·fr·(1 − ((d/D)cosα)²)`
- 검토: 이 식은 볼의 자전 주파수다. 볼 결함은 한 번 자전할 때 내륜과 외륜을 모두 치므로 스펙트럼에서는 2×BSF가 두드러지는 경우가 많다. 문헌과 소프트웨어마다 BSF를 1× 또는 2×로 다르게 정의한다.
- **해결**: 2026-10-07 (Claude, M7.4). P7-5 §2(그림 3: 한 번 자전에 외륜·내륜을 한 번씩, 2×BSF ± FTF)와 `warn` 상자로 두 정의를 설명했다. 사이트 관례는 BSF = 자전 주파수(1배), 볼 결함 박자 = 2×BSF. LAB-BRG-01이 1배·2배를 함께 보인다.

## I-011 [콘텐츠] 오버랩 "Uniform window엔 overlap 무의미" 표현
- 등록: 2026-10-02 · Claude
- 원본 (1-4): "Uniform window엔 overlap 무의미"
- 검토: Uniform에서 겹친 구간끼리는 상관이 커서 평균의 이득이 작은 것이지, 이득이 0인 것은 아니다. 또한 동기 샘플링·과도 신호처럼 Uniform을 쓰는 상황에서는 보통 오버랩 자체가 필요 없다.

  - 2026-10-02 Codex: 본문에 실제 공유 샘플·hop·등가 독립 수 설명. Uniform 4프레임 50%의 CV≈0.5863, 등가 M≈2.91 검증. 본문 검토와 랩 연결 뒤 해결 확인.
- **해결**: 2026-10-02 (Claude, M1.T2). P1-5 §5에 Hann 16프레임 기준 등가 독립 수(0 % 16, 50 % 15.2, 75 % 8.6)와 Uniform 50 % 약 10.9("이득이 더 작지만 0은 아니다")를 적고, LAB-AVG-01 읽음값 "같은 흔들림을 내는 독립 프레임 수"로 확인하게 했다.

- 재발 방지 (AGENTS.md §4에 반영)
  - worktree를 만들기 전에 `git worktree list`와 상위 폴더를 확인한다. 폴더 이름은 대소문자만 다른 이름을 쓰지 않는다.
  - 다른 트랙(에이전트)의 작업 폴더에서는 설치·빌드·git 명령을 실행하지 않는다. 명령을 `cd A && …`로 이어 쓸 때 앞 단계가 실패하면 멈추도록(`&&`) 하고, 실패한 단계 뒤에 다른 폴더로 넘어가는 명령을 같은 줄에 두지 않는다.
