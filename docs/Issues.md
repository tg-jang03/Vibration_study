## I-004 [콘텐츠] AF 반공진법 공식 표기
- 등록: 2026-10-02 · Claude
- 원본 (Phase 0 첫 과제): `AF = 1/(2ζ) = N1/(N2-N1)`
- 검토: Half-power법의 증폭계수는 `AF = N_c1/(N2 − N1)`이다. 분자는 임계속도(피크) N_c1이고, N1·N2는 피크 진폭의 0.707배가 되는 두 회전수다. 분자를 N1로 쓰면 AF가 작게 계산된다.
- 처리: 사이트에는 `N_c` 표기를 쓴다 (Contents §3, LAB-AF-01). 분리여유(Separation Margin) 요구식은 API 원문을 대조한 뒤 기재한다.
- 남은 일: API 684/617 원문 대조 (사용자 보유 자료 확인).

## I-005 [콘텐츠] 평균화 "랜덤 노이즈는 √N로 감소" 표현
- 등록: 2026-10-02 · Claude
- 원본 (1-4): Linear 평균에서 "랜덤 노이즈는 √N로 감소"
- 검토: 평균 방식에 따라 줄어드는 것이 다르다.
  - **RMS(파워) 평균**: 잡음 바닥의 *평균 레벨*은 그대로이고, 바닥의 *흔들림(표준편차)*만 1/√M로 줄어든다. 스펙트럼이 매끈해져서 읽기는 쉬워지지만 톤 대 잡음비 자체는 개선되지 않는다.
  - **벡터(트리거 동기) 평균, TSA**: 트리거와 동기되지 않은 잡음의 *진폭 자체*가 1/√M로 줄어든다. 톤 대 잡음비가 개선된다.
- 처리: LAB-AVG-01에서 두 방식을 나란히 보여주고 본문에서 구분한다 (Contents §5에 반영함).
  - 2026-10-02 Codex: 본문 숫자 예와 코어 테스트로 RMS 평균 레벨 유지·1/√M 흔들림·벡터 파워 1/M 구분. D-024 본문 검토 대기, 랩 연결 뒤 해결 확인.

  3. `Plot`: 라이브러리 로드 실패 시 "불러오지 못했습니다" 문구 표시 (무한 로딩 방지)

- 그래도 개발 화면이 깨지면: 개발 서버 재시작, 필요하면 `npm run dev -- --force` (캐시 재생성)

## I-019 [버그] 랩 hydration 불일치 (React 오류 #418)
- 등록: 2026-10-02 · Claude (M1.3)
- 현상: `/dev/lab-ui/`에서 콘솔에 `Minified React error #418` (hydration 중 텍스트 불일치).
- 원인: 랩 컴포넌트는 빌드 때 서버에서 한 번 그려지고 브라우저에서 다시 그려진다(hydration). 읽음값 표에 넣은 "계산 시간"(`performance.now`)이 서버와 브라우저에서 달라 불일치가 났다.
- 처리: 이런 값은 `useEffect`로 hydration이 끝난 뒤에만 보여준다. 규칙으로 AGENTS.md §6에 추가 — 시간, 시드 없는 난수, `window`·화면 크기처럼 서버와 브라우저에서 달라지는 값은 첫 렌더에 쓰지 않는다.
- **해결**: 2026-10-02 (오류 0건 확인)
- 보강 (2026-10-02, M1.4): 이론상 0인 값에 남는 부동소수점 잡음(예: Im X = −2.7e-15)도 서버(Node)와 브라우저에서 다르게 나와 같은 오류를 냈다. 신호 크기 대비 아주 작은 값은 0으로 표시한다 (`DftCorrelationLab`의 `clean`). 학습자에게도 1e-15 같은 숫자는 혼란스럽다.

## I-021 [버그] 본문 수식 아래첨자 깨짐 (KaTeX 버전 불일치)
