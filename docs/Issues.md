## I-004 [콘텐츠] AF 반공진법 공식 표기
- 등록: 2026-10-02 · Claude
- 원본 (Phase 0 첫 과제): `AF = 1/(2ζ) = N1/(N2-N1)`
- 검토: Half-power법의 증폭계수는 `AF = N_c1/(N2 − N1)`이다. 분자는 임계속도(피크) N_c1이고, N1·N2는 피크 진폭의 0.707배가 되는 두 회전수다. 분자를 N1로 쓰면 AF가 작게 계산된다.
- 처리: 사이트에는 `N_c` 표기를 쓴다 (Contents §3, LAB-AF-01). 분리여유(Separation Margin) 요구식은 API 원문을 대조한 뒤 기재한다.
- 남은 일: API 684/617 원문 대조 (사용자 보유 자료 확인).

## I-006 [콘텐츠] dB 기준값
- 등록: 2026-10-02 · Claude
- 원본 (1-5): "ISO ref 보통 1e-6 m/s or 1e-6 m/s²"
- 검토: ISO 1683의 진동 기준값은 속도 1 nm/s(1e-9 m/s), 가속도 1 µm/s²(1e-6 m/s²), 변위 1 pm으로 알고 있다. 업계에서는 VdB(예: 1e-8 m/s, 1e-6 in/s) 같은 다른 관례도 섞여 쓰인다.
- 처리: LAB-SPC-02에서 기준값을 선택할 수 있게 하고 출처를 표시한다. ISO 1683 원문을 확인한 뒤 확정한다.

## I-008 [콘텐츠] BSF 정의 관례 (1× / 2×)
- 등록: 2026-10-02 · Claude
- 원본 (4-2): `BSF = (D/2d)·fr·(1 − ((d/D)cosα)²)`
- 검토: 이 식은 볼의 자전 주파수다. 볼 결함은 한 번 자전할 때 내륜과 외륜을 모두 치므로 스펙트럼에서는 2×BSF가 두드러지는 경우가 많다. 문헌과 소프트웨어마다 BSF를 1× 또는 2×로 다르게 정의한다.
- 처리: LAB-BRG-01(P6-4, M7.4 — D-027로 번호 변경)에서 정의를 명시하고 1×와 2×를 모두 표시한다.

## I-009 [설계] 규격(ISO/API) 내용 인용 범위
- 등록: 2026-10-02 · Claude
- 현상: ISO 20816, API 684/670 등은 유료 저작물이다. Zone 경계값이나 표를 사이트에 그대로 옮기면 저작권 문제가 생길 수 있다.
- 제안: 개념과 절차는 자체 표현으로 요약하고 출처를 표기한다. 수치 경계값이 필요한 랩(LAB-ISO-01)은 사용자가 보유한 규격에서 값을 입력하는 방식으로 만든다.
- 갱신 (2026-10-02): 저장소가 공개로 정해져 사이트도 공개된다 → 위 제안을 기본 정책으로 적용한다. 규격 표·경계값·본문 문장은 저장소와 사이트에 넣지 않는다. 사용자가 확인하면 상태를 `해결`로 바꾼다.

## I-012 [콘텐츠] "Keyphasor dot 개수 = 차수" 단순화
- 등록: 2026-10-02 · Claude
- 원본 (Phase 5): "Keyphasor dot 개수 = 차수"
- 검토: 안정적인 서브하모닉 1/n X 오빗에서 dot이 n개 찍히는 경우에 해당한다. 비정수 차수(예: 0.43X oil whirl)는 dot이 고정되지 않고 이동한다. 1X + 2X 같은 슈퍼하모닉 오빗에는 그대로 적용되지 않는다.
- 처리: P5-3에서 조건을 명시하고 LAB-ORB-01에서 비정수 차수의 dot 이동을 보여준다 (Curriculum 5-3에 반영함. D-027로 번호 변경).

## I-013 [콘텐츠] 미스얼라인 "각 = 축방향, 평행 = 2X" 단순화
- 등록: 2026-10-02 · Claude
- 원본 (4-1 표): 각 미스얼라인 → 1X + 2X 축방향, 평행 미스얼라인 → 2X 우세
- 검토: 교육용 단순화다. 실제로는 두 형태가 섞여 나오고, 2X 우세가 아닌 경우도 많다. 결정적 증거는 커플링 양쪽 위상(약 180°), 오빗 형태(바나나/8자), Shaft centerline 위치(예하중)다.
- 처리: P6-2에서 단순화임을 밝히고 위상·오빗·Centerline 증거를 우선 제시한다 (Curriculum 6-2에 반영함. D-027로 번호 변경).
